Accessibility Vectors dialog box

The Accessibility Vectors dialog allows you to create and remove accessibility vectors in order to further classify features according to their accessibility.  You can specify the direction from which the features will be machined.

Vector Method

You can define the geometry of a vector on a feature using the Vector Method. To select the vector method for a hole axis, you choose from the following list (list varies based on the geometry type you are selecting):

  • Face Normal

  • Edge/Curve Vector

  • Inferred Vector

Left and Right Arrows

Using the left and right arrows you can cycle through all the accessibility vectors to select a specific vector.

  • Note:

    A hole feature can have one or two accessibility vectors depending on whether it's a blind or through hole.

    If the tool axis defined in the parent MCS geometry group matches any of the accessibility vectors specified for a feature, the feature is included in the feature group.

    If the tool axis in the MCS group is set to All Axes then all the features, regardless of their accessibility vectors, are included in the group.

  • Note:

    Accessibility vectors can not be defined for milling features.
