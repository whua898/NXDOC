Select Machining Feature

Create Machining Rules

Teach Machining Rules

Available after you select a machining rule library node and a machining feature.

Generates the new or modified machining rules to store in the selected machining rule library.

Your custom rule appears in the library hierarchy with the following format:

OPERATION_NAME_FEATURE_TYPE

For example, if your operation name is CAVITY_MILL, and your feature type name is CUSTOM_1, the rule name is CAVITY_MILL_CUSTOM_1.

OK, Apply

Saves the new or modified machining rule in the selected machining knowledge library.

Note:

You must have write permissions to the machining knowledge library. If you do not, an error message is displayed when you select the Teach Operations command.
