Tagging features

Tagging adds User Defined Attributes (UDAs) to geometric entities or features to create a machining feature. Once a geometric entity, such as a point or face, contains the CAM_FEATURE_NAME attribute, it is automatically identified as a machining feature in the Machining Feature Navigator. Tagging lets you add machining features to a model that was not created with features.

You can use tagging to simplify feature classification.

You can tag:

  1. Points

  2. Arcs

  3. Cylindrical faces

  4. Base features and UDF

Each dialog has manufacturing features which contain attributes recognized by NX. For each manufacturing feature, there are default value sets in the dialogs. All information about manufacturing features, attributes and default value sets is provided by the data file. You can customize these dialog value sets in the data files.
