Feature Status

The Feature Status command checks all operations within a feature group, and displays a Regenerate symbol if the tool path is not fully generated. For example, if the feature is blocked by a clamp so that the tool cannot access the feature, or if a tool is not long enough to drill to the full depth of the feature, NX identifies the operations so that you can take appropriate action.
