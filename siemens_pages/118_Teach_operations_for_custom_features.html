Teach operations for custom features

This example shows how to define machining rules for a custom feature using the Teach Operations command. You can also define new machining rules for a standard feature.

Note:

NX can apply these machining rules only to features with the same dimensions as the feature used to teach the operations. To make the rules more general, so that you can apply them to features with different dimensions, you must edit the rules in the Machining Knowledge Editor (MKE). To create general rules without using the MKE application, use the NX command Create Operation Sets.

Before you begin, you must:

  • Teach NX to recognize the custom feature.

  • Fully define the operation or operations to teach.

  1. Open the part that contains the custom feature and fully defined operations.

  2. In the Operation Navigator, right-click the operation or group of operations and choose Object→Teach Operations.

    The Teach Operations dialog box is displayed.

  3. In the Machining Rule Library group, from the Select Library list, select a library for your new custom operations.

    Machining Knowledge

    MillDrill

  4. Select the feature in one of these ways:

    • In the graphics window, select the feature geometry.

    • In the Machining Feature Navigator, select the feature name.

  5. Click Teach Machining Rules .

    NX generates the new machining rules to store in the selected machining rule library. If the operations are not fully defined, NX displays an Information window with warning and error messages to help you make any required corrections.

    Your custom machining rules are placed in alphabetical order within the library hierarchy. The format for the name of each rule is:

    OPERATION_NAME_FEATURE_TYPE

    For example, if your operation name is CAVITY_MILL, and your feature type name is CUSTOM_1, the rule name is CAVITY_MILL_CUSTOM_1.

    Machining Knowledge

    MillDrill

    Bore_S3P_D3

    CAVITY_MILL_CUSTOM_1

    Chamfer_S1H_contour

  6. Click OK or Apply.

    NX saves the new machining rules in the selected machining knowledge library.
