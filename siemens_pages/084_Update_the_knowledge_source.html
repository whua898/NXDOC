Update the knowledge source

If the operation templates or other files used to customize feature-based machining are modified, you must update the machining knowledge source files.

  1. From Windows, choose Start→All Programs→NX x.x→Manufacturing Tools→Machining Knowledge Editor.

  2. Choose View→Options.

  3. In the Settings dialog box, in the Customization group, select the Update Upon Load check box.

  4. Choose File→Open and select the machining knowledge source file to edit from your local folder or from Teamcenter.

  5. After the source file is updated, choose View→Options and clear the Update Upon Load check box.
