Create Feature Process dialog box

Type

Type list

Rule Based

Uses the selected machining knowledge rule libraries to automatically create operations for the selected features. You control which rules to evaluate by selecting the rule libraries.

Template Based

Legacy. Uses the selected template to create operations for the selected features.

Operation Set Based

Replaces template based.

Parameterizes the tool selection, and gives precise control by offering only applicable solutions for all selected features. The operation sets presented depend on the application criteria defined per operation set. You can select only one operation set to apply.

Choose this option when Teach Operation Sets has been used to define one or more operation sets for the selected feature.

Knowledge Libraries

Available when Type is set to Rule Based or Operation Set Based.

Lists the available rule libraries.

Note:

You must select at least one rule library.

Each knowledge library contains rules for creating operations. Different knowledge libraries contain rules for different 加工 areas, such as Milling or Turning.

Template

Available when Type is set to Template Based.

Specifies the part file that contains the process templates. Only the templates that contain operations or the selected features are listed here.

Process Type

Available when Type is set to Template Based.

Displays the process types from the selected template that match the selected features.

Location

Geometry

Specifies which geometry parent to use for the feature processes.

Automatic

Determines the geometry parent automatically based on the part geometry and tool axis.

If the software cannot find a geometry parent with part geometry that matches the feature, the feature process is not created.

Use this option to create operations in multiple geometry parents.

Settings

Group

Specifies how to create the feature processes.

Use Existing

Reuses existing feature processes when possible. Creates a new feature process if an existing feature process is not available.

Always Create New

Creates a new feature process and merges applicable features into the new process.

Per Feature

Creates a new feature process for each feature.
