Machining Feature Navigator columns

Features

Displays the unique identifier for each machining feature or feature group, and the edit status. The default feature name is the feature type followed by an underscore, and a number that is 1 for the first feature of its kind, 2 for the second, and so on. You can rename the feature.

Example:

STEP2_HOLE_10

Feature groups display the feature group icon , and the default feature group name is the feature type preceded by FG_. Feature groups that were manually created prior to NX 11.0.2 display a legacy icon , and the feature group does not display its parameters when you hover over the icon.

Example:

FG_STEP2_HOLE

FG_STEP2_HOLE

Feature groups can display the following status:

Up to Date
Suspected

The feature group has geometry children with definitions that are not up to date.

A feature can be a child of one or more feature groups. The feature may meet the acceptance criteria for one feature group, and not meet the acceptance criteria for another feature group.

If a feature meets the acceptance criteria for a feature group parent, its status appears as follows:

Up to Date
Changed and Updated
Deleted or Not Valid

Out of Date

If a feature does not meet the acceptance criteria for a feature group parent, its status appears as follows:

Up to Date
Changed and Updated
Deleted
Out of Date

For more information on the acceptance criteria, see Feature update acceptance criteria.

Feature Type

Displays the type of machining feature. For example, SIMPLE_HOLE or COUNTER_BORE_HOLE.

Operation Status

Available in the Feature View.

Indicates the machining status of a feature. For example, it shows whether or not all operations for a machining feature have been successfully machined.

Empty

This status indicates that you have not assigned the feature to any geometry group.

Complete

This status indicates that all tool paths of all operations applied to the machining feature in the specified geometry group are successfully generated.

Incomplete

This status indicates that one or more of the operations have failed to generate the tool path.

Regenerate

This status indicates that one or more of the operations does not generate a tool path or is out of date and requires regeneration.

Source

Indicates the source of a manufacturing feature.

CAD

Indicates that the source is a standard NX feature.

UDF

Indicates that the source is a user-defined feature.

Recognized

Indicates that the source is a recognized feature.

Solid Edge

Indicates that the source is a Solid Edge feature.

MW/PDW

Indicates that the source is a Mold Wizard feature, or a Progressive Die Wizard feature.

Tagged

Indicates that the source is a tagged object such as a point, an arc, or a face.

Overridden

Indicates whether any of the attribute values of a manufacturing feature are overridden. The value is YES if any one attribute has been overridden, and NO otherwise.

Multiple Groups

Indicates whether the feature is in multiple geometry groups.

Attributes

The Machining Feature Navigator displays a column for each attribute associated with a machining feature. Attributes may come from the parameters of an NX feature, or KF attributes, or can be user-defined. If a machining feature does not have an attribute defined, but others do, then the attribute cell of this feature is empty.
