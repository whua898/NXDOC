Hole Depth Dialog (KF)

There are three different ways to define Hole Depth: Depth, Model Depth, and Smart Point.

Use Model Depth

Model Depth aids in defining how deep to cut the hole. In the Use Model Depth section you have two choices: Always and Rule.

Always

Selecting Always means that the system Always uses Model Depth on all the features.

Rule

The Rule option determines the use of the Model Depth per feature, based on the Use Model Depth parameter value found in 知识融合. If the value says TRUE then Model Depth is used. If the value says FALSE then the operation looks to the value in Hole Depth Type (defined below) for its value.

Blind Offset (KF)

Calculated depth is reduced by this amount when the hole is a blind hole.

Thru Offset (KF)

Calculated depth is increased by this amount when the hole is a through hole. When Collision Check is toggled on and this offset gouges the part below the hole, the actual offset used is less than the specified value in order to avoid the gouge.

Note:

The Depth Offsets are applicable only when the depth is calculated using the Model Depth.

Hole Depth Type

In the Depth Type section you have two options: Smart Point and Depth/Rule.

Smart Point

If Smart Point is selected the depth value comes from the smart point defined on the features. When mapping the smart point fails, the depth value comes from the value specified for the hole top. To define a smart point on the features use the Point Method (defined below).

Note:

Note that when you use mixed geometry types, such as base features, faces, arcs, and points, you can set the Hole Depth Type to Smart Point and specify the smart point for a variety of features types. For those feature types that do not have smart point specified, the depth value comes from the rule.

Depth/Rule

If Depth/Rule is selected the depth value comes from the Depth value (see Depth below) or rule found in 知识融合.

Point Method

You can define the geometry of a Smart Point on a feature for the depth using the Point Method. In this section of the dialog you have a drop down menu to chose from. Depending on what type of geometry you are selecting, you can select from the following list:

  • Arc/ Ellipse/ Sphere Center

  • Control Point

  • Existing Point

  • End Point

Remove

This button removes the current smart point.

Left and Right Arrows

Using the left and right arrows you can cycle through all the representative features.

Depth (KF)

Use this option when you simply want to enter the value of the hole depth independent of any other types of depth.
