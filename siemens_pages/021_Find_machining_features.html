Find machining features

  1. In the Machining Feature Navigator, right-click in the background and select Find Features.

  2. In the Find Features dialog box, in the Type group, select the search Type:

    To:

    Select this:

    Find existing model features or User Defined Features (UDFs).

    Feature Identification

    Find features by analyzing the model geometry.

    Parametric Feature Recognition

    Find legacy feature types if you used Holemaking in an earlier release.

    Legacy Hole Recognition

    Find legacy feature types if you used Holemilling in an earlier release.

    Legacy Face and Pocket Recognition

    Control feature selection by manually specifying features and their faces when the automatic methods do not produce the desired result.

    Manual Recognition

  3. In the Bodies to Search group, select an option from the Search Method list:

    To:

    Do this:

    Search the Workpiece geometry only.

    Select Workpiece.

    Search all bodies in the work part.

    Select All Bodies.

    Manually select the body to search.

    1. Select Specify.

    2. In the graphics window, select the body to search for features.

  4. In the Features to Recognize group, in the Features to Recognize list, select the check boxes next to the features you want to find.

  5. (Optional) In the Machining Access Direction group, select a vector option. Specify a vector to limit your search to features that are accessed from the same direction. For example, specify Z Axis to find holes that would be drilled by moving in the negative direction along the ZC axis.

  6. (Optional) In the Limit Search Area group, click Select Face and select faces from the graphics window to limit your search to the selected faces.

    Tip:

    On the Top Border bar, select a Face Rule option that helps you to select faces.

  7. (Optional) In the Feature Settings group, select the Assign Color Attribute check box if you have processes that are determined by the feature color.

  8. In the Recognized Features group, click Find Features .

  9. From the Recognized Features list, select any features you do not want and click Remove .

  10. Click OK.
