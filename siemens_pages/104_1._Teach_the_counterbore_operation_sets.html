1. Teach the counterbore operation sets

  1. Unzip reuse_operation_sets.zip, and open teach_counterbores.

  2. Review the operations.

    WORKPIECE
    CBORE_THREADED_MILL
    DRILLING_1
    HOLE_MILLING_1
    THREAD_MILLING_1
    HOLE_CHAMFER_MILLING_1
    CBORE_THREADED_TAP
    DRILLING_2
    HOLE_MILLING_2
    HOLE_CHAMFER_MILLING_2
    TAPPING

  3. In the Operation Navigator, select the two counterbore feature nodes, right-click and choose Object→Teach Operation Sets.

    MCS
    WORKPIECE

    CBORE_THREADED_MILL
    CBORE_THREADED_TAP

    You can select multiple feature nodes if they are of the same feature type.

    In the Teach Operation Sets dialog box, you will define a tool condition for each feature group so that you can use the operation sets for different size holes.

    Operation Sets list:

    • CBORE_THREADED_MILL
      DRILLING_1
      HOLE_MILLING_1
      THREAD_MILLING_1
      HOLE_CHAMFER_MILLING_1
      CBORE_THREADED_TAP
      DRILLING_2
      HOLE_MILLING_2
      HOLE_CHAMFER_MILLING_2
      TAPPING

  4. In the Operation Sets group, select the DRILLING_1 operation.

    DRILLING_1

    Notice that NX also selects the DRILLING_2 operation. This is because the operations are identical.

  5. On the Conditions tab, enter a tool condition to match the tool diameter to the hole diameter.

    1. Select the following in the order shown.

      Parameters group

      • Objects list = TWIST_DRILL

      • Parameters list = DIAMETER

      Operators group

      • =

      Parameters group

      • Objects list = STEP2HOLE_THREAD

      • Parameters list = DIAMETER_2

      Note:

      In this example DIAMETER_1 is 35 mm, and DIAMETER_2 is 14 mm.

      The result appears in the Conditions group, Edit Condition box.

      Copy
      tool.DIAMETER=ftr.DIAMETER_2

    2. Click Validate .

      The result appears in the Conditions box.

      Copy
      tool.DIAMETER=ftr.DIAMETER_2

  6. In the Create Machining Rules group, click Teach Machining Rules .

    Note:

    As long as you do not click Apply or OK, you can cancel your updates if you make a mistake. If you need to delete an operation set rule after saving it to the machining knowledge library, use the Machining Knowledge Editor application.

  7. Enter tool conditions for the HOLE_MILLING_1 operation so that the tool is small enough to engage safely in the drilled hole, and also large enough to mill efficiently.

    HOLE_MILLING_1

    1. Select the following in the order shown.

      Parameters group

      • Objects list = END_MILL_NON_INDEXABLE

      • Parameters list = DIAMETER

      Operators group

      • >=

      Parameters group

      • Objects list = STEP2HOLE_THREAD

      • Parameters list = DIAMETER_2

      Operators group

      • /

      The result appears in the Conditions group, Edit Condition box.

      Copy
      tool.DIAMETER>=ftr.DIAMETER_2/

    2. In the Edit Condition box, type 2.

      The result appears in the Conditions group, Edit Condition box.

      Copy
      tool.DIAMETER>=ftr.DIAMETER_2/2

    3. Click Validate .

      Copy
      tool.DIAMETER>=ftr.DIAMETER_2/2
      Note:

      Spaces are not necessary for most conditions. However, you must add a space before and after the operators - and +.

      The result appears in the Conditions box.

      Copy
      tool.DIAMETER>=ftr.DIAMETER_2/2

  8. Using the same process, enter the second condition and click Validate .

    Copy
    tool.DIAMETER<ftr.DIAMETER_2

    The result appears in the Conditions box.

    Copy
    tool.DIAMETER>=ftr.DIAMETER_2/2
    tool.DIAMETER<ftr.DIAMETER_2

  9. In the Create Machining Rules group, click Teach Machining Rules .

  10. Select the HOLE_CHAMFER_MILLING_1 operation and enter the following tool condition.

    HOLE_CHAMFER_MILLING_1

    Copy
    tool.DIAMETER<ftr.DIAMETER_1

  11. Select the TAPPING operation and enter the following tool condition.

    TAPPING

    Copy
    tool.DIAMETER=ftr.DIAMETER_2

  12. Review your operation sets and make any corrections.

  13. Click OK to save the rules to the Machining Knowledge Library and close the dialog box.

  14. Close the part.
