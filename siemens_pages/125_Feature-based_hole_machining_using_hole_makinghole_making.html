Feature-based hole machining using hole_making

You can use the hole_making operation type template to create the following manual feature-based operations to machine holes:

  • Spot Drilling

  • Drilling

  • Countersinking

  • Tapping

  • Hole Milling

  • Boss Milling

  • Thread Milling

  • Boss Thread Milling

The part to machine can contain features, geometric entities with attributes, features with attributes, or any combination of the three.

Hole Making and Hole Mill

The legacy Hole Making and Hole Mill operation subtypes are used to create templates for Feature Based Machining. They are not intended to create operations.
