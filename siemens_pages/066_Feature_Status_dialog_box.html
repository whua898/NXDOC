Feature Status dialog box

The Feature Status dialog allows you to see the status of each operation within a feature group.

Option

Description

Unfinished Features Columns

The Unfinished Features column displays all the features in the feature group that were not completed during tool path generation. When you select the feature the feature highlights in the graphics window.

Operation Columns

In the Feature Status dialog the system displays a column for each feature and operation in the feature group. For each unfinished feature the system displays one of the following icons in each of the operation columns:

Complete

Incomplete

Regenerate

For example, if your feature group contains three operations, Spot Drill , Drill, and Mill, and the drilling operations of two features within your feature group were not completed during tool path generation, then the Feature Status dialog would look something like this:

Unfinished features

Spot Drill

Drill

Mill

SIMPLE_HOLE_1

SIMPLE_HOLE_2

In this case the Spot Drill operation and Mill operation are both complete for both of the features. Only the Drill operation is incomplete.

Remove

Use the Remove button to select one feature and remove it from the feature group.

Remove All

Use the Remove All button to remove all of the features from the feature group at one time.
