Tool Query Dialog

In the Tool Query dialog you can construct rules for a rule-based tool search.

Units

The Units option allows you to select the units of the tool you are selecting. This makes it possible to search for metric tools in an inch part file and inch tools in a metric part file.

Variable Type

Set the Variable Type to Database Attributes. This lists the tool parameters according to the specified class. These parameters can be used for the rule based tool search.

Clicking a tool parameter displays the parameter in the Query Window where the rule is built.  

KBE Tool Query Rule (&KFRQ())

This tool query function only uses strings that represent a tool query built with KF rules. Instead of defining the tool class and the query in the dialog, you can build it in a dfa function and execute it by calling this function using &KFRQ().

You can use this function when an operation uses tools of different classes, where the library class, its subclass, and the query are dependent on certain features or other criteria.

This option is found under: Tool Query Dialog → Variable Type → KBE Query Rule

Example:

Copy
{&KFRQ(query_from_function())}
Defun: query_from_function()
@{
if ug_cam_ask_FeatureTolerance() = TRUE then 
    # Feature has no tolerance information
    @{ $class_spec << ug_cam_askClassOfClassList("TOOL","TOOL;DRILLING;SPOT_DRILL");
       $class_qry << ug_cam_askQueryOfDbcClass("TOOL",$class_spec);
       $qry << $class_qry+" && DB(Diameter) == &KFR(ug_cam_tool_spot_drill_dia())
 && DB(PointAngle) == 90";
     }  
else 
    # Feature has tolerance information
    @{ $class_spec << ug_cam_askClassOfClassList("TOOL","TOOL;DRILLING;CENTER_DRILL");
       $class_qry << ug_cam_askQueryOfDbcClass("TOOL",$class_spec);
       $qry << $class_qry+" && "+"DB(Diam_1) <= 20";
     }; 
}String;

The result of this example is one of the following strings: 

Copy
[DB(SubType)] == [22] && [DB(Type)] == [03] && [DB(libref)] !=0 && DB(Diam_1) <=20
(Spot Drill)
or
[DB(SubType)] == [21] && [DB(Type)] == [03] && [DB(libref)] !=0 && DB(Diameter) ==
&KFR(ug_cam_tool_spot_drill_dia()) && DB(PointAngle) == 90

(Center Drill)

Based upon the features tolerance information, one of these queries is returned and executed.

Operators

The operators ( >, >=, <, <=, ==, !=, SE, SNE, AND, and OR) are combined with the tool parameters and the KF functions to construct the rules.

By switching the Variable Type to KBE Rule "&KFR("  displays. This fragment is expecting a KF rule to be entered for completion.

Copy
{
    {DB(Diameter) == &KFR(ug_cam_tool_drill_dia_base();)
    }
 && 
     {DB(FluteLength) >= &KFR(ug_cam_drill_depth_base();)
     }
}

Check Query Syntax

This option checks the constructed rule for syntax errors according to the tool query syntax.

Sort Order

Selecting the Sort Order button displays the Sort Order dialog. In this dialog you can indicate the desired sequence of the records in the record set by selecting attributes from the Sort By and Then By drop down menus.

The drop-down menus list the Database Attributes. The attribute that is selected in the Sort By option is the attribute used to create the primary sequence. If you want to sort the sequence further, select attributes in the first and second Then By options.

Selecting Ascending or Descending from the Sort By and Then By list sorts each sequence in an ascending or descending order respectively.
