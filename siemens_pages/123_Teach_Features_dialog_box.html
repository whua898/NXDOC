Feature Type

Select Feature Type

Displays the hierarchy that represents the inheritance relations of all the available feature types. Examples of feature types include holes, slots, faces, and complex custom features.

ShapeFeature - Root feature type node

BLANK - Standard feature

CustomerFeature - Parent node for custom features

CUSTOM1 - Custom feature

Feature Type hierarchy example

Add New Feature Type

Available after you select a feature type node from the hierarchy.

Places the new feature type under the selected node. You must enter a unique name for the new feature type.

Recognition Rule hierarchy example

Add New Rule

Available after you select a standard recognition rule node.

Places the new recognition rule under the selected node. You must enter a unique name for the new feature recognition rule.

A standard recognition rule is a rule that is provided with NX.

Recognition Rule Options

Add matching conditions from:

Lists the available matching conditions. The check boxes are not selected by default.

NX recognizes a feature only if all the selected matching conditions are met.

Feature Faces

Select Face

Lets you select the faces to define your custom feature.

NX finds features whose topology is an exact match to the topology of the faces you select to define your custom feature.

To find features with similar topology that is not an exact match, do either of the following:

  • Edit the recognition rule to make it more general, using the Machining Knowledge Editor.

  • Create multiple recognition rules for the same feature type, in NX. Each rule recognizes slightly different topology.

Create Recognition Rule

Teach Recognition Rule

Available after you select the feature type, the matching recognition rule, and the faces that define your custom feature.

Teaches NX to recognize the new or existing feature type. NX highlights any matching features in the graphics window.

OK, Apply

Saves the new or modified definitions in the selected machining knowledge library. If necessary, saves the new feature type in the classification section of the machining knowledge library.

Note:

You must have write permissions to the machining knowledge library. If you do not, an error message is displayed when you select the Teach Features command.
