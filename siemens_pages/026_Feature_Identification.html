Feature Identification

Feature Identification is one way to define or create CAM features. When identifying the CAD/UD features the system identifies the feature as a whole, not by its individual geometry parts. Use this option when the designer created the part using CAD or UD features.

Note:

Holemaking identifies mirrored user defined features (UDFs). This makes it possible to identify mirrored UDFs, mirrored instances of UDFs, and UDFs in mirrored bodies.
