Set the IPW precision for collision checking

If the IPW resolution is too coarse, it is possible for collision checking to miss small details. For the best results, set the medium IPW resolution to 3-5 times the ratio of model size to smallest detail size. For example, your model has a maximum dimension of 2000 mm, and the smallest detail size is 10 mm. A suggested value would be 4 *2000/10, or 800.

To set the IPW resolution:

  1. Choose File→Utilities→Customer Defaults.

  2. In the Customer Defaults dialog box, select Manufacturing→Simulation & Verification.

  3. Click the IPW tab.

  4. In the IPW Resolutions area, enter 800 in the Medium box.
