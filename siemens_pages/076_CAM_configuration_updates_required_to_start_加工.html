CAM configuration updates required to start 加工

The machining knowledge library for your installation must be in the current format for the Manufacturing application to open. If you use a custom directory structure, or a custom machining knowledge library, you may see the following error message:s

Invalid machining knowledge library version

To correct this error, you must save the machining knowledge library in the new format in one of the following ways.

  • If you use a custom directory structure:

    1. Copy any existing files that you have modified to a backup folder.

    2. Copy the UGII_CAM_MACHINING_KNOWLEDGE_DIR and UGII_CAM_MACHINING_KNOWLEDGE_EDITOR_DIR folders to the appropriate locations in your custom directory structure.

    3. Add any required information from the backup files.

  • If you use custom machining knowledge libraries, for each custom library:

    1. In the Machining Knowledge Editor (MKE), choose File→Open.

    2. Select the machining knowledge library file and click OK.

    3. Choose File→Save.

      The MKE saves the library in the new format.

Version dependent customizations

Teamcenter Integration customers can use Teamcenter functionality to support version dependent customizations. See the following for more details.

  • Manufacturing General→Teamcenter Integration →Import Manufacturing templates into Teamcenter

  • Manufacturing General→Teamcenter Integration →Configure Teamcenter to use the correct manufacturing templates

  • MachiningKnowledgeEditor.pdf help file→TCIN for FBM chapter

Native NX customers should create different configurations to support version dependent customizations.
