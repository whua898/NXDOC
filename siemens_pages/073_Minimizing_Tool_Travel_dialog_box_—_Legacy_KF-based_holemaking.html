Minimizing Tool Travel dialog box — Legacy KF-based holemaking

The Minimizing Tool Travel dialog box displays when you select Minimizing Tool Travel in the Feature Resequence section of the Optimized_NC dialog.

Start and End Feature

Start Feature and End Feature let you select the starting and ending features. This can save machining time by optimizing the transition moves between features.

Note:

If you do not specify the start and end features, they are defined by the software.

Method

The method section has two choices, Standard and Advanced. Standard is the default setting for this option.

Standard

The order of the features is determined in a manner similar to chaining: the second feature is the point closest to the start feature, the third feature is the point closest to the second feature and so on.

Note:

This option takes less time to resequence the feature order than the Advanced option below.

Advanced

This option may take considerably longer processing time than the Standard method in determining the shortest tool path. However, this method increases machine time efficiency.

Based On

If the system detects fixed-axis, then only Distance is available. However, if the machine is multiple-axis, you can select either Distance or Tool Axis. Distance is the default selection for this option.

Distance

The optimization is based on the distance between the holes.

Tool Axis

The optimization is based on the axis of the tool while machining the holes.

Distance Method

The way in which the distance between two features is computed.

Direct

If the Direct option is chosen the direct 3D distance between two features is used for calculating optimization.

With Transition

If the With Transition option is chosen real transition movement between two features is used for calculating optimization.

Resequence

The Resequence button executes the minimizing tool travel optimization based on the options you have selected. It displays the order in which the features will be machined, by placing a number on each feature.
