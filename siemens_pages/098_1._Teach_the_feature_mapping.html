1. Teach the feature mapping

The feature recognition step is optional because you do not need to select a feature to create the mapping rules. However, when you start with a feature:

  • In the Teach Feature Mapping dialog box, NX sets the input type to match the feature that you select to teach.

  • You can look at the feature's parameter values.

  1. Create a teach part with the required feature geometry and attributes.

    Suppose your company has the following mapping requirements.

    STEP1HOLE, no tolerance

    STANDARD_HOLE

    STEP1HOLE, yellow

    TOLERANCED_HOLE

    STEP1HOLE, PMI dimension tolerance grade ≤ 7

    TOLERANCED_HOLE

    STEP1HOLE, face attribute is defined

    TOLERANCED_HOLE

    We will use the 2 holes to the left of the dovetail slot to teach the feature mapping.

  2. Run feature recognition.

    1. Right-click in the Machining Feature Navigator and choose Find Features.

    2. Set the following:

      Type group

      • List = Parametric Recognition

      Geometry to Search group

      • Search Method = All Geometry

      Features to Recognize group

      • Map Features =

      • Recognition =

      • ParametricFeatures→STEPS =

      Machining Access Direction group

      • Method = None

    3. In the Limit Search Area group, click Select Face and select the faces shown.

      Make sure that you select the chamfer faces as well as the cylindrical faces.

    4. In the Recognized Features group, click Find Features .

      You will run feature recognition again when you create your operation sets so that they have your company's assigned feature types.

    5. Click OK.

      step1hole_teach
      STEP1HOLE_1
      STEP1HOLE_2

      Note:

      The feature numbers will vary.

  3. In the Machining Feature Navigator, right-click the standard hole feature and choose Teach Feature Mapping.

    STEP1HOLE_1

    Note:

    If you skipped step 2, right-click in the background and choose Teach Feature Mapping to create the mapping rule. When you select nothing, the Teach Mapping Features dialog box opens with the BLANK feature input. In either case, you can always change the input feature type in the dialog box.

  4. Create a mapping rule that maps holes with any color except #6 to the feature type STANDARD_HOLE.

    1. In the Teach Feature Mapping dialog box, set the following:

      Feature Type Mappings group

      • Select Input Type = STEP1HOLE

        By default, NX sets the input type to match the feature type that you selected to teach.

    2. From the Select Output Type list, select STEP1HOLE.

      • Select Output Type

        MachiningFeature
        DrillMillFeature
        ParametricFeature
        STEP
        STEP1HOLE

    3. Click Add New Type and name your new feature type STANDARD_HOLE.

      STEP1HOLE
      STANDARD_HOLE

      Note:

      Custom features are shown with blue font in the Teach Feature Mapping dialog box.

    4. With the STANDARD_HOLE output type selected, from the Select Rule list, select the Mapping node.

      Mapping

    5. Click Add New Rule and name your new rule as shown.

      Mapping
      map_2_STANDARD_HOLE

    6. On the Conditions tab, select the following in the order shown.

      Parameters group

      1. Objects list = STEP1HOLE

      2. Parameters list = COLOR

      Operators group

      1. < >

        Use the operator <> when your condition is not equal to a specific value.

      The result appears in the Conditions group, Edit Condition box.

      Copy
      in.COLOR<>

      You will assign the color value for yellow to the condition.

    7. In the Edit Condition box, after <>, enter 6 and click Validate .

      The result appears in the Mapping Conditions box.

      Copy
      in.COLOR<>6

  5. Click Teach Mapping Rule and then click OK to save the mapping rule and close the dialog box.

    Note:

    As long as you do not click Apply or OK, you can cancel your updates if you make a mistake. If you need to delete a mapping rule after saving it to the machining knowledge library, use the Machining Knowledge Editor application.

  6. In the Machining Feature Navigator, right-click the toleranced hole and choose Teach Feature Mapping.

    STEP1HOLE_2

    In the Teach Feature Mapping dialog box, notice that the name of the custom feature you created in the previous step is shown in blue font.

  7. Repeat step 4 to create a mapping rule that maps holes with the color 6 to the toleranced hole feature type.

    • Name your feature type TOLERANCED_HOLE.

      STEP1HOLE
      STANDARD_HOLE
      TOLERANCED_HOLE

    • Name the rule map_2_TOLERANCED_HOLE_COLOR.

      Tip:

      You must select the Mapping node each time you create a new mapping rule.

      Mapping

    Result:

    Mapping
    map_2_STANDARD_HOLE
    map_2_TOLERANCED_HOLE_COLOR

    Finished condition:

    Copy
    in.COLOR=6

  8. Click Teach Mapping Rule .

  9. Create a second mapping rule for the TOLERANCED_HOLE feature type that maps holes with ISO class <=7.

    Name the rule map_2_TOLERANCED_HOLE_PMI.

    Mapping
    map_2_STANDARD_HOLE
    map_2_TOLERANCED_HOLE_COLOR
    map_2_TOLERANCED_HOLE_PMI

    To create the following finished condition, you will select parameters and manually enter commas to separate the parameters.

    Copy
    IT_class_ISO(in.DIAMETER_1,in.DIAMETER_1.UPPER,in.DIAMETER_1.LOWER)<=7

    1. With your new rule map_2_TOLERANCED_HOLE_PMI selected, on the Conditions tab, select the following in the order shown.

      Operators group

      1. Fx

        This button makes the Functions list available.

      Parameters group

      1. Functions list = IT_class_ISO

      2. Objects list = STEP1HOLE

      3. Parameters list = DIAMETER_1

      Result:

      Copy
      IT_class_ISO(in.DIAMETER_1

    2. In the Edit Condition box, enter a comma.

      Result:

      Copy
      IT_class_ISO(in.DIAMETER_1,

    3. In the Parameters list, expand the DIAMETER_1 node, and select UPPER.

      Result:

      Copy
      IT_class_ISO(in.DIAMETER_1,in.DIAMETER_1.UPPER

    4. In the Edit Condition box, enter a comma.

      Result:

      Copy
      IT_class_ISO(in.DIAMETER_1,in.DIAMETER_1.UPPER,

    5. In the Parameters list, under the DIAMETER_1 node, select LOWER.

      Result:

      Copy
      IT_class_ISO(in.DIAMETER_1,in.DIAMETER_1.UPPER,in.DIAMETER_1.LOWER

    6. In the Operators group, select ) and <=.

      Result:

      Copy
      IT_class_ISO(in.DIAMETER_1,in.DIAMETER_1.UPPER,in.DIAMETER_1.LOWER)<=

    7. In the Edit Condition box, enter 7 and click Validate .

      Result in the Mapping Conditions box:

      Copy
      IT_class_ISO(in.DIAMETER_1,in.DIAMETER_1.UPPER,in.DIAMETER_1.LOWER)<=7

  10. Click Teach Mapping Rule .

  11. Create a third mapping rule for the TOLERANCED_HOLE feature type that maps holes with the face attribute MW_HOLE_FIT.

    Name the rule map_2_TOLERANCED_HOLE_FACE.

    Mapping
    map_2_STANDARD_HOLE
    map_2_TOLERANCED_HOLE_COLOR
    map_2_TOLERANCED_HOLE_PMI
    map_2_TOLERANCED_HOLE_FACE

    The following is your finished condition:

    Copy
    is_defined(in.MW_HOLE_GUIDE_PIN_FIT)

    For this condition, NX checks only for the existence of the face attribute MW_HOLE_GUIDE_PIN_FIT. The attribute can have any value. MW_HOLE_GUIDE_PIN_FIT is a custom attribute that is available in the standard machining knowledge library supplied with NX.

    1. With your new rule map_2_TOLERANCED_HOLE_FACE selected, on the Conditions tab, select the following in the order shown.

      Operators group

      1. Fx

      Parameters group

      1. Functions list = is_defined

      2. Objects list = STEP1HOLE

      3. Parameters list = MW_HOLE_GUIDE_PIN_FIT

      Result:

      Copy
      is_defined(in.MW_HOLE_GUIDE_PIN_FIT

    2. In the Operators group, select ).

      Result:

      Copy
      is_defined(in.MW_HOLE_GUIDE_PIN_FIT)

    3. Click Validate .

      Result in the Mapping Conditions box:

      Copy
      is_defined(in.MW_HOLE_GUIDE_PIN_FIT)

    4. Click Teach Mapping Rule .

  12. Assign a priority to the map_2_TOLERANCED_HOLE_COLOR mapping rule for the TOLERANCED_HOLE feature.

    It is important to assign a priority rule because NX uses the priority together with the conditions to determine which feature to map. A larger priority number indicates a higher priority.

    If you do not assign a priority, NX applies the first rule, in random order, which has all of its conditions satisfied.

    1. Select the TOLERANCED_HOLE output type.

    2. Select the mapping rule.

    3. Click the More tab.

    4. In the Priority box, type 100 and press Enter.

    5. Click Teach Mapping Rule .

  13. Repeat step 12 to assign priorities to the map_2_TOLERANCED_HOLE_PMI and map_2_TOLERANCED_HOLE_FACE rules.

  14. When all of the rules are complete, review them for correctness, and then click OK to save the rules and exit the dialog box.
