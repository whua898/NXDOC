Machining Feature Navigator group

Button

Description

Feature View

Displays features individually in the Feature View of the Machining Feature Navigator. Features can be shown in the context of the part or assembly to which they belong.

Group View

Displays features in groups in the Group View of the Machining Feature Navigator. Features belong to a group if they satisfy the classification criteria. Geometry groups are shown in the context of the workpiece and the MCS.

Find Features

Opens the Find Features dialog box to let you control how NX creates features.

Tag Points

Opens the Tagging Attributes to Points dialog box to let you add user defined attributes to points.

Tag Arcs

Opens the Tagging Attributes to Arcs dialog box to let you add user defined attributes to arcs.

Tag Faces

Opens the Tagging Attributes to Faces dialog box to let you add user defined attributes to faces.

Tag Features

Opens the Tagging Attributes to Features dialog box to let you add user defined attributes to features.

Create Feature Process

Applies either the knowledge library rules or the template to the selected features to create a machining process. To create the machining process, NX does the following:

  • It creates the appropriate operations for each feature.

  • It selects or retrieves tools for the operations.

  • It sets the tool, program, and geometry parents for the operations.

  • It merges features with identical processes into geometry groups.

Delete

Deletes the selected manufacturing feature.

Expand All/

Collapse All

Expand and collapse the nodes in the Feature column.

Information

Opens the Information window.

You can control the display of the Information window with the Display Information During Group Creation customer default. If the default is turned on, the Information window opens when a template is applied. The default value is ON.

This window contains the following:

  • The tool query

  • The name of the Alternate Groups of Operations

  • The operation status, which is the machining status of a feature.

  • A list of tool names that satisfy the tool query and the detailed information on the selected tool.

  • The classification criteria value of each feature group

Tip:

To find a customer default, choose File→Utilities→Customer Defaults, and click Find Default.

Create Filter

Opens the Create Filter dialog box to let you set and apply filter criteria. When you apply a filter, only machining features that satisfy the filter criteria are displayed; otherwise all machining features in the part file are displayed.

Export Feature

Lets you export selected manufacturing features to a PLMXML file so that you can exchange them with other applications. These features include:

  • NX CAD features, such as pockets, holes, or user defined features that have been processed as manufacturing features.

  • Tagged geometry entities (points, arcs, faces and features) with the CAM_FEATURE_NAME attribute.

PLMXML is an XML data exchange file format. For more information on this emerging format see PLM XML.

Export To Browser

Lets you export the current Machining Feature Navigator view to an HTML file.
