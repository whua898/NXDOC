Tagging Arc and Face Dialogs

In the Tagging Attributes to Arcs dialog and the Tagging Attributes to Faces dialog there is a filter section with filter settings.

Filter

There are four items in the filter section for these dialogs:

Diameter

When you toggle this option on and a range is entered into the fields, only arcs or faces whose diameters are inside the range are selected.

Ignore Partial Circle/Cylindrical Faces

When you toggle this option on arcs and faces that are not full circles, meaning those not 360 degrees, are ignored.

Same Axis Direction

When this option is toggled on all arcs or faces that are selected must have parallel axes.

Don't Tag if Part of Base Features

When this option is toggled on arcs and faces that belong to a base feature (SIMPLE_HOLE, COUNTER_BORE_HOLE, COUNTER_SUNK HOLE) are not selected.

Hole Axis

Automatic IJK

Check the Automatic IJK box to have the system automatically define the IJK for the hole axis of any one or all of the entities in your part. Once this is checked, select the entity or entities you want to have automatically defined and the system computes them.

Reverse IJK

If you want to reverse the direction of the hole axis after the IJK has automatically been determined, you can do so by checking the Reverse IJK box.

Display Axes

Click the Display Axes button to display the automatically generated IJK hole axes in the Graphics Window.
