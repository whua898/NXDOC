Teach Feature Mapping

Use the Teach Feature Mapping command to teach NX how to map the standard feature types supplied with NX to your company-specific feature types. It is not necessary to use the Machining Knowledge Editor.

The following example shows the mapping requirements for a company that wants to recognize holes that must be machined to tolerance separately from holes that do not require a specific tolerance, and also wants to assign the two feature types different names.

STEP1HOLE, not yellow, no defined tolerance

STANDARD_HOLE

The Teach Feature Mapping dialog box guides you through the process of defining mapping rules that specify the required conditions. You can also assign priority values to control the order in which NX tries to apply the mapping rules. When you click OK or Apply, NX adds your mapping rule to the Machining Knowledge library.
