Tagging Attributes To Features Dialog

Feature Name

The first option in this dialog is Feature Name. This option has a drop down list that contains all the feature names that can be used. If you select a feature name, the following items change:

Feature Description

This field contains a brief description of the feature selected in the Feature Name field.

Feature Templates

This field includes the default value sets of the feature selected in the Feature Name field.

Filter

The filter options for this dialog are the following:

Diameter

When you toggled this option on and a range is entered into the fields, only features whose diameters are inside the range are selected.

Depth

When you toggled this option on and a range is entered into the fields, only features whose depths are inside the range are selected.

Dialog Attributes

The attributes that are listed in each dialog depend on the Feature Name that has been selected. For a description of the 24 attributes that are delivered with the system go to the Classification Attributes List section. Keep in mind it is also possible to customize more attributes. Therefore, if the attribute you are looking for was customized into the system, it is not in the chart.
