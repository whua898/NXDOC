4. Test the operation set teaching

  1. Make sure that the Display Information During Feature Mapping and Group Creation customer default is turned on.

    Restart your NX session if necessary. The information display will help you to troubleshoot any issues you find during testing.

    Tip:

    To find a customer default, choose File→Utilities→Customer Defaults, and click Find Default .

  2. Open your test part.

  3. Right-click the title bar of the Machining Feature Navigator and choose Find Features.

  4. Set the following:

    Type group

    • List = Parametric Recognition

    Geometry to Search group

    • Search Method = All Geometry

    Features to Recognize group

    • Map Features =

    • Mapping→STANDARD_HOLE =

    • Mapping→TOLERANCED_HOLE =

    • Recognition =

    Machining Access Direction group

    • Method = None

    Feature Settings group

    • Assign Color Attribute =

  5. In the Recognized Features group, click Find Features and then click OK.

  6. In the Machining Feature Navigator, right-click the selected features and choose Create Feature Process.

  7. Set the following:

    Type group

    • List = Rule Based

    Knowledge Libraries group

    • Machining Knowledge→OperationSets =

    Location group

    • Geometry = Automatic

    Settings group

    • Groups = Use Existing

  8. Click OK.

    The Information window gives details on the operation selection process that you can use to analyze the reasoning process.

  9. In the Operation Navigator, review the feature groups and operations that NX creates.

    Sample feature groups are shown. Your feature numbers and operation numbers may vary from the ones shown.
