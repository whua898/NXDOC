Hole Top

The hole top is where the cutting tool enters the hole as it begins to machine the hole.  

Point Method

You can define the geometry of a smart point on a feature for the hole top using the point method. For the Hole Top Point Method selection you have a drop down menu to choose from. Depending on what type of geometry you are selecting, you can select from the following list:

  • Arc/ Ellipse/ Sphere Center

  • Control Point

  • Existing Point

  • End Point

Remove

This button removes the current smart point.

Left and Right Arrows

Using the left and right arrows you can cycle through all the representative features.
