Teaching NX the set of operations to machine a feature

You can teach NX your company's requirements for machining specific features without having to learn the FBM reasoning process by using the Teach Operation Sets command.

In NX, each group of operations that machine a single feature is an operation set. After you establish the operations, and the conditions that control when you use the operations, you can teach the operation set to NX. In the following example, a company uses two different operation sets to machine holes without a specified tolerance.

  • STANDARD_HOLE_DRILL_TO_SIZE drills a hole to size when the matching drill is available.

  • STANDARD_HOLE_MILL_TO_SIZE drills a hole, and then mills to size when a matching drill is not available.

Use the following process to teach operation sets:

  1. Create one or more feature groups with recognized features.

    The feature group name is the name of the operation set that you teach. The recognized features can be standard types or your own type. If you use your own type, you will also need to teach NX the feature mapping. You need as many features groups as you have different operation sets. In the previous example, feature groups 1 and 2 are the same feature type, however there are different conditions under which you want NX to apply each operation set.

  2. Create operations as children of the feature groups.

    The operations must be feature based.

  3. Use the Teach Operation Sets command.

    You define the generalized conditions that specify when NX applies an operation set. For example, use the STANDARD_HOLE_DRILL_TO_SIZE operation set if there is a matching drill, otherwise use the STANDARD_HOLE_MILL_TO_SIZE operation set.

    Typically you define tool sizes and operation parameters relative to the feature size so that the tool, feature, and operation parameters are interrelated.

The Teach Operation Sets dialog box guides you through the process of defining generalized conditions. You specify when NX can use an operation set, the size of the tools, and additional parameters. You can also assign priority values to control the order in which NX tries to apply the operation sets. When you click OK or Apply, NX adds your operation sets to the Machining Knowledge library.

In most cases, you do not need to use the Machining Knowledge Editor (MKE) application. However, you can still use the MKE to inspect and edit the generated results.

Teach parts

You can use any part to teach NX operations sets. However, as a best practice, we recommend the following:

  • Use separate parts for teaching.

  • Place all of your teaching parts in a central location.

  • Assign a naming convention to your teaching parts to help you identify them.

  • Assign a naming convention to the operation sets that you will teach.
