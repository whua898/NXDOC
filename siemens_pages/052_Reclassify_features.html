Reclassify features

To reclassify features in an FBM_GEOM parent group, you must select them first in the Machining Feature Navigator.

  1. Right-click the Machining Feature Navigator and choose Undock.

  2. Pin open the Operation Navigator.

  3. Place the Operation Navigator and the Machining Feature Navigator side by side.

  4. In the Operation Navigator, select the FBM_GEOM geometry group FBM_GEOM_1.

    MCS_MILL

    WORKPIECE

  5. In the Machining Feature Navigator, control-select or shift-select the features to reclassify.

    You can select features from the Group view or the Feature view of the Machining Feature Navigator.

  6. In the Operation Navigator, right-click FBM_GEOM_1 and choose Edit.

    The FBM Geom dialog box is displayed.

  7. Click Reclassify .

  8. Click OK.

  9. The Group view of the Machining Feature Navigator shows that the features are added to FBM_GEOM_1.
