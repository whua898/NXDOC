Machining Feature Navigator commands

Object commands

The following commands are available when you right-click an object in the Machining Feature Navigator.

Approve Changes

How you use the Approve Changes command depends on whether the selected feature meets the criteria for the feature group that contains it.

  • If the selected feature still meets the feature group criteria, NX changes the status from Changed and Updated to Up to Date .

  • If the selected feature no longer meets the feature group criteria, NX displays a different Changed and Updated icon. You should first confirm that the new feature parameters are correct, and that the feature still requires the same operations as the other features in the feature group.

    When you approve the changes, the Up to Date icon indicates that the feature does not meet the group criteria, but has been checked and is acceptable.

    If the new parameters or operations are not acceptable, you can take one or more of the following corrective actions:


    • Manually remove the feature that is causing the problem.

    • Modify the feature group.

      You can modify the feature group classification criteria, or drag the feature group to a new parent.

    • Use the Redistribute command to restore the feature geometry distribution of the selected feature group.

    • Use the Recreate command to create a new feature process for the selected feature group.

Approve

Changes the status of a feature group from Suspected to Up to Date .

Use when a feature group contains features that do not meet the group criteria, to indicate that the feature group has been checked and is acceptable.

Edit Feature CSYS

Edits the position and orientation of a feature. You can change the CSYS settings either dynamically in the graphics window or in the Edit Feature CSYS dialog box.

In the Details panel of the Machining Feature Navigator, the Overridden column displays a check mark for the modified CSYS attributes.

Find Related Operations

Highlights operations in the Operation Navigator that belong to the machining feature or the geometry group that is selected in the Machining Feature Navigator.

This command is available when you right-click the selected machining feature or geometry group.

Find Related Tools

Highlights the tools in the Operation Navigator that belong to the machining feature or the geometry group that is selected in the Machining Feature Navigator.

This command is available when you right-click the selected machining feature or geometry group.

Machining Feature Navigator, Group View

Operation Navigator, Machine Tool View

Recreate

Creates a new feature process for the selected feature groups.

This command is available in the Group View when you right-click a feature geometry group.

The status of the feature geometry group before Recreate is Suspected. The status of the machining feature is Changed and Updated.

The status of the feature geometry group after Recreate is Up to Date. The status of the machining feature is Changed and Updated. The machining feature needs to be approved.

Redistribute

Corrects the distribution of faces and boundaries in the selected feature group. Use this command when features have been added or removed from the feature group.

This command is available in the Group View when you right-click a feature geometry group.

Show Machining Areas

Shows the machining areas within a feature. A feature machining area is a subset of your feature, such as floor, wall, or drive surface geometry, that lets you use multiple operations to machine a complex feature.

Background commands

The following commands are available when you right-click a column heading, or right-click in the background of the Machining Feature Navigator.

Delay Updates

Lets you delay automatic updates to machining features until all changes to the part have been finalized.

Force Updates

Lets you update all out-of-date features without switching the Delay Updates command off.

Freeze Column, Unfreeze Column

Control column visibility when you scroll horizontally.

Hide Undefined Attributes

Hides those machining feature attributes that have no defined values, in the Details panel of the Machining Feature Navigator.

Parametric recognition adds empty attributes when there are no values to extract from the model file. For example, multiple attributes remain empty when side roughness is not completely defined. Hide undefined attributes so that you can more easily locate the attributes that you want.

Hide Undefined Attributes on

This command is available when you right-click a column heading of the Details panel of the Machining Feature Navigator.

Show Feature CSYS

Turns on or off the coordinate system that displays the position and orientation of machining features.

This command helps you to control the direction display for machining features without using a customer default.

Show Feature CSYS on

Show Feature CSYS off

Show Feature Only

Shows features without the part or assembly component to which they belong.
