Delaying feature updates

When you are outside of the Manufacturing application, NX does not update the machining features. Within Manufacturing, you can choose when NX should update the machining features.

  • Use the Delay Updates command to delay automatic updates to machining features until all changes to the part have been finalized.

    Turn the delay on, do multiple changes to the part or do multiple repositions of the part, and then turn the delay off whenever the updates should be handled.

  • Use the Force Updates command to force an update of all out-of-date features without switching the Delay Updates command off.

When you delay updates, NX:

  • Marks the features which still have pending feature updates Changed and Out of Date .

  • Does not generate operations which depend on the out-of-date machining features and displays an alert message.

To generate the out-of-date operations, turn off the Delay Updates command or use the Force Updates command.
