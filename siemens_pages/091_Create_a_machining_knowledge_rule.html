Create a machining knowledge rule

  1. Start Machining Knowledge Editor in native NX or in Teamcenter Integration.

  2. In the library tree, right-click the root node of the machining knowledge source, (for example, machining_knowledge ) and choose New.

  3. In the Multiple Class Selection dialog box, select the Rule check box and click OK.

  4. In the library tree, click the new rule.

  5. In the Name box, enter a name for the rule.

  6. In the InputFeatures (lwf.) box, press F8 and select the input feature type from the list.

  7. In the OutputFeatures (mwf.) box, press F8 and select the output feature type from the list.

  8. In the Resources (tool) box, press F8 and select the tool type from the list.

  9. In the OperationClass (oper.) box, press F8 and select the operation type from the list.

  10. Define the conditions of the machining rule. You can:

    • Define in-process features.

    • Define a preferred process and an alternate process to use if the tool is not available.

    • Make the rule valid for a subset of part materials.

    • Make the rule valid for a subset of machines.

    Two fixed attributes are added to each operation type: oper.PARENT_METHOD and oper.PARENT_PROGRAM. Defining these attributes in Machining Knowledge Editor is optional, but if you define them, you can control where operations are distributed in the Operation Navigator.

  11. Access additional functions, such as Non Cutting Moves or User Defined Events, with a Rule Add-on.

See the Machining Knowledge Editor online Help for more information on procedures for this application.
