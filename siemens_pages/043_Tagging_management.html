Tagging management

Data Files

Tagging uses four data files. They are found under two different folders: metric and English. Each folder contains two data files: tagging.dat and tagging_fea.dat. The tagging.dat file is used when tagging points, arcs and faces. The tagging_fea.dat is used when tagging base features.

Organization Of Data Files

You can customize the organization of the tagging.dat file with an infinite amount of features. Each feature has three pages. On the first two pages you have the option to hide or display the page. You can also assign the page a name and decide which attributes it contains. On the third page you can only change the name.

Each feature can contain 25 attributes. For each attribute, you have the option to provide default values. You can also provide feature templates for each feature.  

Note:

The names of base features must not be changed.

For tagging_fea.dat file, there are only three features: SIMPLE_HOLE, COUNTER_BORE_HOLE and  COUNTER_SUNK_HOLE. The names and sequence must not be changed.
