Feature Selection options

Option

Description

Mode

Lets you add or remove one or more features from the feature group. Selected features are highlighted in the Graphics region.

Append

Lets you add features to the group.

Edit

Lets you delete features from the group.

Append

Adds the current feature to the feature group.

Append All

Adds all the highlighted features to the feature group.

Remove

Removes the current feature from the feature group.

Remove All

Removes all the features from the feature group.

Class Selection

Lets you select more than one feature at a time in the feature group.

Left and Right Arrows

Lets you cycle through all the features.

Note:

Instead of cycling through all the features you can select the feature in the Graphics region.
