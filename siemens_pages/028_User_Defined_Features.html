User Defined Features

The system is delivered with a set of 知识融合 (KF) enabled User Defined Features (UDFs) that already contain CAM specific information.

For more information on user defined features, see User Define Feature in the Modeling help.

Once one of the UDFs is instantiated, a respective UDF class is created within 知识融合.  UDFs are common standard features for machinery and require only a minimum input parameter set that comes with each UDF. You must enter a value for each parameter in the parameter set for each UDF.  All the other modeling relevant data is stored in external data files and can be customized accordingly. These files can be found in the following folder: ../mach/resource/feature.  

Instead of feature parameters, KF attributes are evaluated for the feature-based machining process.
