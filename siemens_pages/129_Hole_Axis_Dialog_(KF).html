Hole Axis Dialog (KF)

The hole axis is the vector along which the cutting tool travels to machine the hole.

Hole Axis Type

Select the hole axis Type from the drop down list. This list includes Vector, Rule, and Rule if no Vector.

Vector

If Vector is selected Hole Axis uses the smart vector defined on the features.

Rule

If Rule is selected the Hole Axis uses the values of I,J,K.

Rule if no Vector

If Rule if no Vector is selected, the system uses the smart vector if one is defined. Otherwise it uses the values of I,J,K.

Vector Method

You can define the geometry of a vector on a feature for the hole axis using the Vector Method. For the Hole Axis Vector Method selection you have a drop down menu from which to chose. Depending on what type of geometry you are selecting, you can chose from the following list:

  • Normal Face

  • Edge/Curve Vector

  • Inferred Vector

Reverse Direction

Once the axis has been set the Reverse Direction button reverses the direction of the smart vector.

Remove

This button removes the current smart vector.

Left and Right Arrows

Using the left and right arrows you can cycle through all the representative features so that a vector can be specified on the feature type you want. For example, points, arcs, faces, base features, and UDFs.

IJK (KF)

This is where you define the I,J,K values for the hole axis. If Rule is selected when selecting the hole axis values, these I,J,K values are used.
