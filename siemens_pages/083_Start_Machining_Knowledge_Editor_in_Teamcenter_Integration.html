Start Machining Knowledge Editor in Teamcenter Integration

  1. From Windows, choose Start→All Programs→NX x.x→Manufacturing Tools→Machining Knowledge Editor

  2. Choose View→Options.

  3. In the Settings dialog box, in the Teamcenter Integration group, select the Use Teamcenter Integration check box.

  4. In the Infodba Password box, enter your password.

  5. Select the Teamcenter Integration mode.

    Note:

    You must enter the path to TC_DATA and TC_ROOT in the short format. For example, use C:\Progra῀1 instead of C:\Program Files.

    For two-tier mode

    For four-tier mode

    1. Enter your installation folder or browse for the location.

    2. Enter your database or browse for the location.

    Enter the connection string.

  6. Exit MKE and start it again.

  7. Choose File→Open.

  8. In the Open Machining Knowledge Source dialog box, select the required item revision of your machining knowledge source.

    The dialog box displays all item revisions of the CAM Machining Knowledge folder in the Home folder of the infodba user.

Note:

Steps 2–6 are only required once for each user. The options retain their settings.
