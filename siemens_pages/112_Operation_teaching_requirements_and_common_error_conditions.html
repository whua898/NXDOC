Operation teaching requirements and common error conditions

The following requirements must be met for you to teach NX the operations for a custom feature:

  • You must have write permissions to the machining knowledge library.

  • Each operation must have a tool defined, and the tool must be available in the machining knowledge library.

  • All operation parameters must be defined in the machining knowledge library customization.

    For information on the machining knowledge library customization, see the Customization view chapter of the Machining Knowledge Editor Training document located in the UGII_CAM_BASE_DIR\machining_knowledge_editor\bin\English\Help folder of your NX installation.

Unknown class or parameter

You may see the following error message when a class is not defined in the machining knowledge library customization:

Error: Unknown class:

Error type

Solution

Operation or geometry parent class

  1. In NX, add the template subtype to a template used by the machining knowledge library.

  2. In the Machining Knowledge Editor, update the machining knowledge library customization.

Feature class or parameter

Edit the feature class in the machining knowledge library customization.

Tool class or parameter

Edit the tool class in the tool database.

For example, the dbc_tool_ascii.def file, which is in the UGII_CAM_BASE_DIR\resource\library\tool\ascii\ folder.

UDE class or parameter

Edit the UDE customization file.

For example, the ude.cdl file or the Siemens_Cycles_plus_ude.cdl file, which are in the UGII_CAM_BASE_DIR\resource\user_def_event folder.

Cycle parameter

Edit the Cycle customization file.

For example, the Siemens_Cycles_plus_ude.cdl file, which is in the UGII_CAM_BASE_DIR\resource\user_def_event folder.
