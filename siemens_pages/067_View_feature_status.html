View feature status

  1. In the Operation Navigator, in the Geometry View, select the feature or features.

  2. Right-click and select Object→Feature Status.

    The software displays the Feature Status dialog with all unfinished feature(s) of the selected feature group in the Unfinished features column.

  3. Use the scroll bar to scroll down the operation columns that the system displays for each feature in the feature group.

  4. Check the status of each operation in the operation columns.

  5. To remove the geometry feature, select the feature you want to remove and then select the Remove button.

  6. To remove all of the geometry features in the dialog, select the Remove All button.
