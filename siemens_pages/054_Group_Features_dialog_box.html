Group Features dialog box

Features to Group

Method

Specifies the input machining features used to create the feature groups.

All Features

Uses all machining features in the part file.

Below Top Face

Uses all machining features below the selected faces.

Specify

Uses the machining features that you select from the graphics window or the Machining Feature Navigator.

NX adds machining features to the new feature groups only if they are not part of another feature group.

Feature Types

List

Lists the unique feature types of the available input features. NX adds machining features to the new feature groups only if their feature type is selected here.

Machining Access Direction

Method

(Optional) Specifies the machining access direction filter.

Specify Vector

Adds machining features to the new feature groups only if their access direction is the same as one of the specified vectors and is within the specified tolerance value.

Group By

Identical Attributes

(Optional) Specifies which attributes to consider when grouping features.

None

Does not consider attribute values when grouping features.

All

Groups only those features that have identical attribute values.

Predefined

Groups features that have identical diameters, thread pitch, and number of steps. NX ignores the values of all depth attributes, including tolerances, chamfers and thread lengths.

Machining Access Direction

(Optional) Groups only those features that have the same machining access direction.

Location

Geometry

Specifies which geometry parent to use for the feature groups.

Automatic

Determines the geometry parent automatically based on the part geometry and tool axis.

If NX cannot find a geometry parent with part geometry that matches the feature, the feature group is not created.

Use this option to create feature groups in multiple geometry parents.

Feature Groups

Create Feature Groups

Creates and lists the feature groups in the Feature Groups list. You can group additional features with different criteria and add them to this list.

Click OK to create the feature groups in the Operation Navigator

Remove

Removes the selected feature group.
