Defining a custom feature for feature teaching

To fully define the custom feature that you want to teach NX, include the following.

  • A coordinate system (CSYS) to position and orient the feature.

  • Annotated PMI to define the parameters of the feature.

CSYS and datum plane support

Feature teaching fully supports all CSYS subtypes which reference a combination of points, edges, and faces or datums of the feature geometry.

Feature teaching supports CSYS subtypes which reference the following types of datum planes.

  • Two Lines, using edges or centerlines

  • Bisector, using planar faces or datum planes

You must select geometry that belongs to the feature to define the datum plane.

Datum CSYS and Datum Plane are on the Home tab, in the Geometry group.

Annotated PMI

Use PMI dimensions and surface finishes to define the parameters for the new feature type. The text is used to define the names of the parameters and the associated geometry is used to calculate their values during feature recognition.

The text type must be After . For surface finishes, the Title attribute of the surface finish determines the feature attribute name.

You can add logical conditions, such as LENGTH > WIDTH OR WIDTH > 10, to PMI dimensions to constrain the value of the feature parameters. To use these conditions, in the Teach Features dialog box, select the PMI Annotations check box under Add Matching Conditions From.

If you specify a tolerance type for the PMI dimension, such as Equal Bilateral Tolerance , the Teach Features command automatically generates the _UPPER and _LOWER tolerance parameters, and the feature recognition extracts the corresponding tolerance values.

You can use symbolic thread annotation to define threaded hole or boss cylindrical faces.

Annotated PMI warning condition

If the annotated PMI on the feature you teach NX references a point, edge, face or datum that does not belong to the feature geometry, the following message is displayed.

WARNING: ‘PMI name’ is skipped: unrelated reference geometry
