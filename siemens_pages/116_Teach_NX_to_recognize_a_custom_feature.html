Teach NX to recognize a custom feature

This example shows how to define parametric recognition rules for a custom feature. Before you begin, you must fully define the custom feature, preferably in a separate part that is used only for teaching.

  1. (Optional) In the Machining Knowledge Editor, create a new empty library for your custom recognition rules.

    It is preferable to store your custom recognition rules in a separate library.

  2. In NX, open the part with the custom feature.

    1 Feature to teach

  3. Activate feature teaching in one of these ways:

    • Right-click in the background of the Machining Feature Navigator and choose Teach Features.

    • Choose Home tab→Feature group→Teach Features .

    The Teach Features dialog box is displayed.

  4. In the Feature Type group, from the Select Feature Type list, select a parent node for your new custom feature.

    MachiningFeature

    BLANK

    CustomerFeature - Parent node for custom feature

  5. Click Add New Feature Type .

  6. Enter a name for your new feature type.

    MachiningFeature

    BLANK

    CustomerFeature

    CUSTOM1

  7. In the Recognition Rule group, from the Select Rule list, select a parent node for the new rule that will recognize your custom feature type.

    Recognition

    CustomRecognitionRuleLibrary

    ParametricFeatures

  8. Click Add New Rule .

  9. Enter a name for the rule.

    Recognition

    CustomRecognitionRuleLibrary

    CUSTOM1

  10. (Optional) Select the check box next to any required matching conditions.

    For example:

    • If the feature has assigned face colors, select the Face Colors check box.

    • If the dimensions of your custom feature must match certain criteria, select the PMI Annotations check box.

      The PMI Annotations matching condition includes dimension tolerances, surface finishes, and logical conditions.

  11. In the graphics window, select the faces to define your feature.

  12. In the Create Recognition Rule group, click Teach Recognition Rule .

    This step teaches NX to recognize the new or modified feature type.

    NX highlights any matching features in the graphics window.

    Matching features with a face color matching condition

    Matching features without a face color matching condition

  13. Click OK or Apply.

    NX saves the new or modified definitions in the selected machining knowledge library. If necessary, NX also saves the new feature type in the classification section of the machining knowledge library.
