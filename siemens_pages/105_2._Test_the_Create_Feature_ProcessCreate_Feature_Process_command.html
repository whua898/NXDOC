2. Test the Create Feature Process command

  1. Make sure that the Display Information During Feature Mapping and Group Creation customer default is turned on.

    Restart your NX session if necessary. The information display will help you to troubleshoot any issues you find during testing.

    Tip:

    To find a customer default, choose File→Utilities→Customer Defaults, and click Find Default .

  2. Open the test_reuse_op_sets part.

    The test part has several counterbored hole features. Some have chamfers, and some have threads.

  3. In the Machining Feature Navigator, right-click the STEP2HOLE_THREAD_25 and STEP2HOLE_THREAD_26 features and choose Create Feature Process.

  4. Set the following:

    Type group

    • List = Operation Set Based

    Knowledge Libraries group

    • CBORE_THREADED_MILL
      DRILLING_1
      HOLE_MILLING_1
      THREAD_MILLING_1
      HOLE_CHAMFER_MILLING_1
      CBORE_THREADED_TAP
      DRILLING_2
      HOLE_MILLING_2
      HOLE_CHAMFER_MILLING_2
      TAPPING

      Notice that the included operations display to help you select the appropriate operation set.

    Location group

    • Geometry = Automatic

    Settings group

    • Groups = Use Existing

  5. Click OK.

    The Information window gives details on the operation selection process that you can use to analyze the reasoning process.

  6. In the Operation Navigator, review the feature groups and operations that NX creates.

    WORKPIECE
    CBORE_THREADED_MILL
    DRILLING_1
    HOLE_MILLING_1
    THREAD_MILLING
    HOLE_CHAMFER_MILLING_1

  7. Generate and inspect the operations.

    WORKPIECE
    CBORE
    DRILLING_1
    HOLE_MILLING_1
    THREAD_MILLING
    HOLE_CHAMFER_MILLING_1

    Notice that the HOLE_CHAMFER_MILLING_1 operation does not machine the feature without a chamfer.
