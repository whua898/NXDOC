Add graphics to the Manufacturing Feature Navigator Preview panel

  1. Create .tif format images for each feature to add to the Preview panel.

    Name the images to match the feature names. For example:

    • Create a step1hole.tif graphic for the STEP1HOLE feature.

    • Create a counter_bore_hole.tif graphic for the COUNTER_BORE_HOLE feature.

  2. Add the feature image graphics to one of the following locations defined in the ugii_env_ug.dat file:

    • UGII_CAM_FEATURE_DATA_DIR\images\

      The default location for UGII_CAM_FEATURE_DATA_DIR is mach\resource\feature.

    • UGII_CAM_FEATURE_IMAGES_DIR

      The default location for UGII_CAM_FEATURE_IMAGES_DIR is mach\resource\feature\images.

    • UGII_BITMAP_PATH

    The ugii_env_ug.dat file is located in the ugii folder of your NX installation.
