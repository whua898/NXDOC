Attributes

You must provide attributes in order to use Hole Making for identification and evaluation if a model contains only geometry entities. This may be the case if you are importing a part from a different system.

Attributes might also be necessary on base features (SIMPLE_HOLE, COUNTER_BORE_HOLE, COUNTER_SUNK_HOLE, SYMBOLIC_THREAD) or UDFs. This could be the case if CAM specific information such as tolerance or surface finish is needed to obtain a Holemaking process.

There are different ways of attaching attributes to a model. However, in the end attributes must be tagged to either hole faces, hole edges, arcs or points that represent a hole. When dealing with counterbore or countersink holes, you must tag the model's top, the larger part of the hole, when tagging the hole face or hole edge.

This example shows what each tagged item looks like in the Holemaking template provided with the system.

  1. Feature SIMPLE_HOLE

  2. UDA (Face Tag)

  3. UDA (Edge Tag)

  4. UDA (Arc Tag)

  5. UDA (Point Tag)

The orange color in the above picture displays the section of the entity that is selected when using that specific type of tag. For example, look to number three. When the edge tag is used it selects the top edge of the geometric entity. Therefore, the top edge is orange in the above picture while the rest of the entity remains white.
