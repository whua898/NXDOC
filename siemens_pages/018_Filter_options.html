Filter options

Current page

Save

Saves the filter in the system registry so that it is available to use in other CAM setups.

Save in Part

Saves the filter in the file containing the CAM setup. This can be the part file or an assembly.

For more information on CAM setup files, see Initializing the CAM setup.

Active Filters list

Controls what is displayed in the Machining Feature Navigator palette. Lets you filter by feature type and by common feature attributes (parameters). Select the attribute or feature type name to specify the desired condition from the lists at the bottom of the dialog box.

Common Attributes

Common Attributes filters are:

Status

Filters by machining status:

  • None

  • Generated

  • Incomplete

  • Not Generated

See Feature Status for the status definitions.

Overridden

Allows filtering of features whose attribute(s) are overridden.

  • Yes – One or more attributes are overridden

  • No – No attributes are overridden

Direction

For hole features

Filters hole features by their direction. Choose an option from the Vector Method list to specify a vector direction relative to the absolute CSYS.

The axis of each activated hole feature is compared against this vector. A hole feature can either have one axis (blind hole) or two axes (through hole). If one of these axes is aligned to one of the specified vectors, the feature is listed in the Machining Feature Navigator.

Geometry

Specifies that only features with faces that are somehow connected to the specified geometry (faces or bodies) are shown in the Machining Feature Navigator. This allows you to explicitly narrow the scope of listed features to either the selected bodies or faces. If no geometry is specified, all features are listed.

Number of Axes

For hole features

Filters hole features by their amount of axis. Options are:

  • Not Available - The axis cannot be determined, and the feature is possibly not a hole feature.

  • 1 -The feature has one axis (blind hole)

  • 2 - The feature has two axes (through hole).

Set Number of Axes to equal or not equal to the axis option.

Feature Types

A feature type is shown when the check box is selected.

Filter Criteria list

Displays the filter criteria for the selected Common Attributes or Feature Types filter. Filter criteria shown with a l are applied with an Or condition. Filter criteria with a + are applied with an And condition.

Delete

Removes the selected entry from the Filter Criteria list.

Clear Filter

Removes all entries from the Filter Criteria list.

And

Adds this criteria to the Filter Criteria list with an And condition.

Or

Adds this criteria to the Filter Criteria list with an Or condition.

Saved page

Lists the filters saved in the system registry.

Apply

Applies the selected filter to the Machining Feature Navigator.

Delete

Deletes the selected filter from the filter list.

Saved in Part page

Lists the filters saved in the CAM setup file.

These filter settings are saved when the cam setup file is saved.
