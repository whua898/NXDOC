Engage_into_type (KF only)

This integer parameter defines how to engage into the hole. There are three possible methods: none, center axis, and center ramp. The corresponding values are 0, 1, and 2, respectively. When the parameter is set to None, there is no engage. When it is set to Center Axis, the tool engages linearly from the hole top to the cut level along the center of the hole. When it is set to center ramp, the tool ramps from the hole top to the cut level along the hole axis.

Note:

When the cut method is helical, the center ramp option behaves the same as the Center Axis. Also, the engage move is always linear for the helical cut method.

Retract_back_out_type (KF only)

This integer parameter defines how to back out during retract. There are two possible methods: none and center. The corresponding values are 0 and 1. When the parameter is set to none, the tool does not retract to the center after the cut. When it is set to center, the tool always retracts to the center after the cut.

Suppressed (KF only)

This Boolean parameter defines whether or not to suppress the Hole Milling operation. The operation is suppressed if this parameter is set to TRUE.
