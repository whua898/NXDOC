Optimized NC dialog box

Feature

List

Lists the machining features in the order that they are machined. You can move selected features up or down in the list to manually change the machining order.

Sequence

Optimization

Specifies how to reorder the geometry sequence.

Closest

Creates a path that moves from each location to the next closest location.

Shortest Path

Creates a path that travels the shortest overall distance.

Primary Direction

Lets you machine parts with holes arranged in a grid using a zig or zig-zag pattern to minimize tool travel. Whenever possible, NX keeps the transition motions parallel to the axis or vector that you specify as the primary pattern direction.

Reorder List

Applies the selected Optimization option to the list.

Note:

The dialog box displays the default settings each time you open it.

Reload Order From Operations

Loads the sequence defined before you created the OPTIMIZED_NC program parent. This option lets you experiment with sequencing and then return to the original sequence.

Non Cutting Moves

Opens the Non Cutting Moves dialog box where you can specify transfer motions, avoidance motions, and collision checking for non-cutting moves.

Actions

Generate

Generates the optimized tool path.

Replay

Refreshes the graphics window and replays the tool path.

Verify

Provides options for letting you animate the tool path.

List

Displays a text listing of the tool path in an Information window.
