Map Features

Fully configurable functionality helps you map one machining feature to another. You can:

  • Map the standard recognized feature types into your company's custom User Defined Feature types (UDF).

  • Map your specific UDF feature types into the standard recognized feature types.

The Machining Knowledge Editor includes a mapping between the Advanced Hole Features obtained with feature identification and the corresponding parametric features.

The mapping mechanism can serve to merge your company's existing FBM technologies with the rule-based approach. You might map from one feature to another if:

  • You have automatic machining process selection configured for your UDF and want to machine a part that was designed not using your company's standards.

  • You would like to apply the standard automatic machining processes supplied with NX to your UDF.
