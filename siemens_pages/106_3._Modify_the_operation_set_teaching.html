3. Modify the operation set teaching

  1. Open the teach_counterbores part.

  2. In the Operation Navigator, select the CBORE_THREADED_MILL node, right-click and choose Object→Teach Operation Sets.

    MCS
    WORKPIECE

    CBORE_THREADED_MILL

    You will add a condition so that the CBORE_THREADED_MILL operation set is only available when the thead method for a feature is set to Milled.

    Operation Sets list:

    • CBORE_THREADED_MILL
      DRILLING_1
      HOLE_MILLING_1
      THREAD_MILLING_1
      HOLE_CHAMFER_MILLING_1

  3. Select the feature group.

    CBORE_THREADED_MILL

  4. On the Conditions tab, add a new application condition.

    1. Select the following in the order shown.

      Parameters group

      • Parameters list = THREAD→METHOD

      Operators group

      • =

    2. In the Edit Condition box, after =, enter "Milled" and click Validate .

      The result appears in the Conditions box.

      Copy
      ftr.THREAD.METHOD="Milled"

      You have defined a condition that lets NX apply this operation set only to features with the thread method set to Milled.

  5. In the Create Machining Rules group, click Teach Machining Rules .

  6. Review your operation sets and make any corrections.

  7. Click OK to save the rules to the Machining Knowledge Library and close the dialog box.

  8. Close the part.
