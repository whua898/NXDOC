ug_oper_askAccessibleVectors()

This function returns a list of accessibility vectors by analyzing the shape and nature of a hole feature and can be used at the operation level to define the hole axis direction of an operation. The function returns either one (blind holes) or two vectors (through holes).

For blind holes the system returns the open side vector.

For through multi-diameter holes the system returns the vector that points toward the largest diameter side as the first vector in the returning list.

For countersunk holes the system returns the vector that points toward the countersunk as the first vector in the returning list.

For single cylinder through holes the system returns two vectors. The order is random but might be altered by a Z of MCS vector comparison.

For more information go to ug_compAccessibleVectorsMCS().
