Hands-on: Teach operation sets - best practices

Click here to download the parts.

This hands-on workflow shows how to organize your company's best practices for machining a feature type.

Note:

You must have write permissions for your machining knowledge library, and a Machining Knowledge Editor Author license to teach the operation sets. We recommend that you make a backup copy of your machining knowledge library before you try this workflow.

The example supposes that your company wants CAM programmers to choose which operation set to use when they machine counterbored holes. You can use the same workflow for any feature type. In this workflow you do the following:

  1. Teach the operation sets, using a prepared part. There is one operation set to mill the threads, and one operation set to tap the threads.

    Note:

    The steps to teach your operations sets are the same whether you want NX to automatically choose the operation sets to use, or you want the CAM programmer to choose the operation sets to use. However, you can choose to define fewer conditions when the CAM programmer makes the choice.

  2. Test the operation set teaching.

    You will use the Operation Set Based option of the Create Feature Process command, because this workflow is for a process where the CAM programmer decides which operation set to use for the selected features.

  3. Modify the operation set teaching to add an application condition.

  4. Test the updates.
