Machining Knowledge Editor Settings options

Customization

Update Upon Load

Updates the machining knowledge source with any changes to the selected NX configuration and customization files.

Changes to the referenced files affect the feature types, operation types, tool types, machines, and part materials available in the machining knowledge source.

Teamcenter Integration

Use Teamcenter Integration

Lets you modify the files for a Teamcenter Integration installation.

Note:

MKE supports the same versions of Teamcenter as the current NX release.

Infodba Password

Lets you enter your Teamcenter password.

Running in 2-tier Mode

Installation Directory [TC_ROOT]

Specifies the directory where Teamcenter is installed.

Database [TC_DATA]

Specifies the database you are modifying.

Running in 4-tier Mode

Connection String

Specifies the Web server and the Web server's application name used to communicate with Teamcenter over the Web. The default is http://localhost:7001/tc/aiws/aiwebservice.

For more information on running Teamcenter in 4-tier mode, see Running from the command line in Teamcenter four-tier environment in Teamcenter Integration for NX.
