Hole Depth Dialog

Hole Depth Type

In the Depth Type section of the dialog you have two options: Smart Point and Depth/Rule.

Smart Point

If Smart Point is selected the depth value comes from the smart point defined on the features. If mapping the smart point fails, the depth value comes from the value specified for the hole top. To define a smart point in the features, use the Point Method (defined below).

Note:

Note that when you use mixed geometry types, such as base features, faces, arcs, and points, you can set the Hole Depth Type to Smart Point and specify the smart point for a variety of features types. For those types of features that do not have smart point specified, the depth value comes from the rule.

Depth/Rule

If Depth/Rule is selected the depth value comes from the value in the Depth field (see Depth below) or the rule found in 知识融合.

Point Method

You can define the depth of a feature with a smart point by using the Point Method option. In the Point Method section of the dialog you have a drop down menu from which to chose. Depending on what type of geometry you are selecting, you can chose from the following list:

  • Arc/ Ellipse/ Sphere Center

  • Control Point

  • Existing Point

  • End Point

Remove

This button removes the current smart point.

Left and Right Arrows

Using the left and right arrows you can cycle through all the representative features.

Depth

Use this option when you simply want to enter the value of the hole depth independent of any other types of depth.
