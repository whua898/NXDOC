Conditions tab

Parameters

Objects list

Displays the objects for which you can define parameters. The available objects depend on your selection in the Operation Sets hierarchy. If you select a feature group, only the ftr parameters are displayed.

ftr

Lets you define feature parameters that control when you apply the operation set.

oper

Lets you define operation parameters such as feed rates and offset values.

tool

Lets you define tool parameters.

addon

Lets you define additional parameters. In the Machining Knowledge Editor, these are called Rule Add-ons. For example, to define a safe clearance distance for non cutting moves:

  • Processes list = NcmDefault

  • Objects list = addon

  • Parameters list = SafeClearanceDistance

Parameters

Lists the available parameters. Select a parameter name to add it to your condition.

Functions

Available when you click the Fx button in the Operators group.

Lists the available functions. Select a function name to add it to your condition.

Operators

Includes commonly used operators. Click an operator to add it to your mapping rule condition. Click the < > operator to add a not equal condition. Click the Fx operator to make the Functions list available in the Parameters group.

Conditions

Edit Condition

Displays the text for the condition you are currently editing.

Note:

  • You must enter values less than 1 with a leading zero.

    For example, if you enter .5, NX displays a syntax error message. You must enter 0.5.

  • You must add a space before and after the operators - and +.

Validates the condition in the Edit Condition box. Moves the condition to the Conditions box, or displays an error message if there is a syntax error.

Conditions

Displays all of the conditions for the selected application or operation or add-on object. To modify an existing condition, select it in the Mapping Conditions box, then make your changes in the Edit Condition box.

More tab

Feature Group

Priority

Specifies the priority assigned to the operation set.

It is important to assign a priority rule because NX uses the priority together with the conditions to determine which operation set to apply. A larger priority number indicates a higher priority.

If you do not assign a priority, NX applies the first operation set, in random order, which has all of its conditions satisfied.

Create Machining Rules group

Teach Machining Rules

Available after you define and validate the conditions for an object.

Generates the new or modified machining rules to store in the machining rule library.

OK, Apply

Available when you have write permissions to the machining knowledge library.

Saves the new or modified machining rule in the machining knowledge library specified in the UGII_CAM_MACHINING_KNOWLEDGE_DIR environment variable.
