Teach Features

Use the Teach Features command to define parametric recognition rules for feature types. You can:

  • Create a new custom feature type.

  • Create a new custom recognition rule for any new or existing feature type, including the standard feature types supplied with NX.

  • Modify an existing custom recognition rule.

    You cannot modify a standard feature recognition rule, such as CORNER_NOTCHES.

  • Define multiple recognition rules for the same feature type.

    For example, you can define a recognition rule with a face color matching condition, and another recognition rule without the matching condition. You can define one recognition rule for a feature with a chamfer, and another recognition rule for a feature without a chamfer.

After you select the feature geometry in the part, the command automatically generates the recognition code and stores the results in a machining knowledge library. New feature types and their parameters are available for reuse immediately after they are created.
