Start Machining Knowledge Editor in native NX

  1. From Windows, choose Start→All Programs→NX x.x→Manufacturing Tools→Machining Knowledge Editor.

  2. Choose File→Open and select the machining knowledge source file to edit.

    Note:

    • The initial folder is defined in: UGII_CAM_MACHINING_KNOWLEDGE_DIR.

    • The machining knowledge source file supplied with NX is: machining_knowledge.xml
