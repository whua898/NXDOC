Create a rule-based feature process from selected features

This example shows how to create operations, tool groups, geometry, and methods for selected features.

  1. In the Machining Feature Navigator palette, select the features for which to create operations.

    Press and hold Ctrl or Shift to select multiple features.

  2. Right-click the selected features and choose Create Feature Process.

  3. In the Create Feature Process dialog box, from the Type list, select Rule Based.

  4. Specify the machining knowledge library to use for creating your operations.

    • In the Knowledge Libraries group, select MillDrill.

    Each knowledge library contains rules for creating operations. Different knowledge libraries contain rules for different 加工 areas, such as Milling or Turning.

  5. Specify the geometry parent.

    • In the Location group, from the Geometry list, select WORKPIECE.

    You can also select Automatic.

  6. Specify how to create the feature process.

    • In the Settings group, from the Groups list, select Use Existing.

    The software reuses existing feature processes, or creates a new process if an existing process is not available.

  7. Click OK.

    The software applies the knowledge library rules to the selected features to create a machining process. To create the machining process, NX does the following:

    • It creates the appropriate operations for each feature.

    • It selects or retrieves tools for the operations.

    • It sets the tool, program, and geometry parents for the operations.

    • It merges features with identical processes into geometry groups.
