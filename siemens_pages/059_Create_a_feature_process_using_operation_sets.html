Create a feature process using operation sets

This example shows how to create operations, tool groups, geometry, and methods for selected features by using templates that are stored as operation sets in the machining knowledge library.

  1. In the Machining Feature Navigator, right-click the features to machine and choose Create Feature Process.

    Tip:

    • Press and hold Ctrl or Shift to select multiple features.

    • Make sure the selected features are all of the same feature type. For example, select either STEP2HOLE features or STEP2HOLE_THREAD features.

  2. In the Create Feature Process dialog box, from the Type list, select Operation Set Based.

  3. In the Knowledge Libraries group, review the operation set list, and select the appropriate operation set.

    NX displays only the operation sets that you can apply to all of the selected features.

    • If you select more than one feature type, the list is blank.

    • The operation sets are defined using the Teach Operation Sets command. For more information on defining operation sets, see Hands-on: Teach operation sets - best practices.

    • NX excludes operation sets with application conditions that do not match the selected features.

    Notice that the included operations display to help you select the appropriate operation set.

    Example:

    CBORE_THREADED_MILL
    DRILLING_1
    HOLE_MILLING_1
    THREAD_MILLING_1
    HOLE_CHAMFER_MILLING_2

  4. In the Location group, from the Geometry list, select the geometry parent for your operations.

  5. In the Settings group, from the Groups list, select Use Existing, to specify how to create the feature process.

    The software reuses existing feature processes, or creates a new process if an existing process is not available.

  6. Click OK.

    The software creates a machining process for the selected features, using the operations from the operation set. To create the machining process, NX does the following:

    • It selects or retrieves tools for the operations.

    • It sets the tool, program, and geometry parents for the operations.

    • It merges the features into a geometry group.

    • It creates the operations from the operation set for each feature.

      If a feature does not require an operation, NX omits the feature from the operation. If none of the features require an operation, NX omits the operation.

      Drilling operation drills both holes.

      Chamfer milling operation omits the feature without a chamfer.
