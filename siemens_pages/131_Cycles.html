Cycles (KF)

You can edit a cycle by selecting the cycle from the option list and clicking the Edit Cycle button. The Cycle Parameters dialog displays with parameters based on the cycle you selected. You can edit these parameters.

Systems Cycles

Currently CAM supports thirteen cycles:

  1. Drill

  2. Drill,Text

  3. Drill,Csink

  4. Drill,Deep

  5. Drill,Deep,BreakChip

  6. Drill,Tap

  7. Drill,Bore

  8. Drill,Bore,Drag

  9. Drill,Bore,NoDrag

  10. Drill,Bore,Back

  11. Drill,Bore,Manual

  12. Peck Drill

  13. Break Chip

These cycles are presented as system cycles. The system cycles have a predefined base set of parameters. You can't change these parameters.  However, you can add more parameters to the system cycles through the ude.cdl file found under Mach-→ Resource-→ user_def_event.

Example

SYS_CYCLE indicates that you are adding a parameter to a system cycle. This example shows that you are adding a coolant type parameter to a drill cycle.

Copy
SYS_CYCLE Drill
  { 
   PARAM coolant_type 
      { 
       TYPE  o
       DEFVAL "0" 
       OPTIONS "0","1","2","3" 
       UI_LABEL "Coolant Type"
      } 
 }

System cycles output the events identical to current Point-to-Point events. For more information go to Manufacturing Milling-→ Point to Point-→ Cycle Options and Cycle Parameters.

User Defined Cycles

You can create user defined cycles and add them to the list of system cycles through the ude.cdl file found under Mach-→ Resource-→ user_def_event. The description of the cycle is user definable using a language similar to the language of User Defined Events (UDEs). Defining the cycles is similar to defining UDEs. You can define as many cycles as desired. This specification is done as a part of the machine definition. You can then edit or replace the defined cycle.

Example

CYCLE indicates that you are adding a User Defined Cycle.

Copy
CYCLE standard_drill
   { 
   UI_LABEL "standard drill"
   PARAM dwell_type 
       { 
        TYPE o 
        DEFVAL "Off" 
        OPTIONS "Off","On","Seconds","Revolutions" 
        UI_LABEL "Dwell" 
        } 
   PARAM dwell_value 
        { 
         TYPE i 
         DEFVAL "0" 
         UI_LABEL "Dwell Value" 
         } 
   PARAM cycle_option 
        { 
         TYPE o 
         DEFVAL "Off" 
         OPTIONS "Off","On" 
         UI_LABEL "Option" 
         } 
   PARAM cycle_cam 
        { 
         TYPE i 
         DEFVAL "0" 
         TOGGLE Off 
         UI_LABEL "CAM" 
        } 
  }
