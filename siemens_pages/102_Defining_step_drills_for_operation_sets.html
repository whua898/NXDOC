Defining step drills for operation sets

这是什么？

You can fully define a stepped tool, both in the Machining Knowledge Editor (MKE) and when you teach operation sets within NX.

Within the Teach Operation Sets dialog box, NX identifies the tool type as STEP_DRILL, and includes the following step parameters, where n represents the segment, or step number:

  • Seg_angle_n

  • Seg_diameter_n

  • Seg_height_n

  • Seg_radius_n

Conditions that use the step parameters are supported.

Example: 
Copy
tool.Seg_diameter_1=ftr.DIAMETER_1
Example: 
Copy
tool.Seg_angle_1 = 3.14159 * mwf.ANGLE_TOP_CHAMFER / 90

For this example, the tool angle is in radians. The feature chamfer angle is half of the tool angle, and is in degrees.
