ug_oper_askHoleTopsAndBottoms()

This function returns a list of points, representing the hole tops and hole bottoms on interrupted hole features. The point lists can be utilized within a hole making operation by the User Defined Tool Path Processor to calculate cut positions and iterate between cutting and rapid modes in order to avoid air cutting on interrupted hole features.

See also ug_cam_udo_drill_interrupted() in ug_cam_samples.dfa

Example of ug_oper_askHoleTopsAndBottoms()

Example: $pnt_list << ug_oper_askHoleTopsAndBottoms();

Result: {{top_point1, bottom_point1}, {top_point2, bottom_point2}, …}.
