Create a rule-based process from the Workpiece or MCS

  • In the Machining Feature Navigator palette, in the Group View, right-click the Workpiece or MCS and choose Create Feature Process.

The software:

  1. Executes the Find Features command.

  2. Adds the found features to the Manufacturing Feature Navigator.

  3. Applies the knowledge library rules to all features without assigned operations. To create the machining process, NX:

    • Creates the appropriate operations for each feature.

    • Selects or retrieves tools for the operations.

    • Sets the tool, and program for the operations.

    • Merges features with identical processes into geometry groups.

  4. Adds the matching feature processes below the selected Workpiece or MCS.

Note:

The Find Features and Create Feature Process settings are specified in the File→Utilities→Customer Defaults dialog box on the Manufacturing→Geometry→Features tab.
