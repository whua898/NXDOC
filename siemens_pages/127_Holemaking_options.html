Holemaking options

Note:

In the Holemaking dialog and Hole Mill dialog documentation there are many parameters with (KF) in their name. This means that you can define these parameters in both the dialog box and the KF rule. When you define these parameters in both locations, NX uses the information that you enter last. For example, if you define a KF rule for a parameter and then later define this same parameter in a dialog box, the NX uses the information you entered in the dialog box.

See Common operation options for common options not described here.

Geometry options

Specify Hole Top

The hole top is where the cutting tool enters the hole as it begins to machine the hole.

Select the Hole Top icon from the HOLE_MAKING dialog.

  • If the hole top has not yet been selected click the Select button.

  • If the hole top has been selected and you would like to edit or reselect your choice, click the Edit or Reselect button.

This displays the Hole Top dialog.

When specifying the hole top, one of the features in the feature geometry group under which the operation sits is presented for selection. Specifying the hole top for this feature is enough to satisfy the hole top specification for all the features in this feature type. This is because all the features in this feature type are identical, based on the selected classification criteria, and the hole top can be mapped to all features in this feature type.

Specify Hole Axis (KF)

The hole axis defines the vector along which the cutting tool travels to machine the hole.

There are three ways to define the Hole Axis: Vector, Rule, and Rule if no Vector.

Select the Hole Axis icon.

  • If the hole axis has not yet been selected click the Select button.

  • If the hole axis has been selected and you would like to edit or reselect your choice, click the Edit or Reselect button.

This displays the Hole Axis dialog.

When specifying the hole axis with a Smart Point, one of the features in the feature geometry group under which the operation sits is presented for selection. Specifying the hole axis for this feature is enough to satisfy the hole axis specification for all the features in this feature type. This is because all the features in this feature type are identical, based on the selected classification criteria, and the hole axis can be mapped to all features in this feature type.

In KF this attribute is called hole_axis_ijk. It stands for Hole Axis. It's controlled by a vector where the three (3) values represent the vector relative to the absolute coordinate system. The system will evaluate this parameter if no hole axis is defined (selected) in the operation.

Specify Hole Depth (KF)

There are three different ways to define Hole Depth: Depth, Model Depth, and Smart Point.

In this dialog you define Hole Depth by using a Smart Point.

Select the Hole Depth icon.

  • If the hole depth has not yet been selected click the Select button.

  • If the hole depth has been selected and you would like to edit or reselect your choice, click the Edit or Reselect button.

This displays the Hole Depth Dialog.

When specifying the hole depth with a Smart Point, one of the features in the feature geometry group under which the operation sits is presented for selection. Specifying the hole depth for this feature is enough to satisfy the hole depth specification for all the features in this feature type. This is because all the features in this feature type are identical, based on the selected classification criteria, and the hole depth can be mapped to all of them.

Note:

For cylinder UDA features, using the smart object may result in incorrect mapping. You should use the IJK 知识融合 rule for cylinder UDA features instead of the Smart Point.

In KF this attribute is called maximum_depth_distance. It stands for Hole Depth. It controls the hole depth if the use_model_depth parameter is set to false and the depth within the operation is not specified by a smart point.

Tool options

Query

You can define a tool query to specify the conditions to use in selecting a tool for the operation. This query specified in an operation is in addition to the query specified in the Method Group to which the operation belongs.

Check Flute Length

When you select Check Flute Length, the system determines the required length of the flute while computing the tool query. This ensures that the flute will be long enough to drill all the holes in the feature group, unlike number three below. You can use this option with or without the IPW option.

Check Tool Length

When you select Check Tool Length, the system determines the overall length of the tool while computing the tool query. This ensures that the tool will be long enough to drill all the holes in the feature group, unlike number four above. You can use this option with or without the IPW option.

Allow Oversize Tool (KF)

Allow Oversize Tool enables you to use a tool with a larger diameter than the hole it is going to machine.  This is useful when tapping or machining toleranced holes. Allow Oversize Tool is only available if the DEPTH cycle parameter is set to MODEL DEPTH and it only works if the holes are solid modeled.

  • Percent of Tool (KF)

    The tool diameter used in the actual depth calculation is reduced by the value of the percent that is entered in this field.

Tool Control Point (KF)

The control point is the point that is used when computing the actual depth. It is the control point that goes to the actual depth of the hole that you are machining. You have two options for this point: Tool Tip and Tool Shoulder.  If you choose Tool Tip it is the tip of the tool that reaches the depth of the hole. If you choose the Tool Shoulder, it is the shoulder of the tool that reaches the depth of the hole; this causes the actual tip of the tool to go beyond the depth of the hole. Tool Shoulder is only effective on through holes.

In KF this attribute is called control_point_type. It stands for Tool Control Point. It's controlled by an integer value where a zero (0) value sets the Tool Control Point to Tool Tip and a one (1) value sets the Tool Control Point to Tool Shoulder.

  • Tool Tip is an end point of the tool along the center of the tool axis.

  • Tool Shoulder is a point on the first cutting diameter of the tool along the center of the tool axis, except on the Step Drill. Step Drill has a parameter to define the Shoulder Distance.

    Note:

    Tool Shoulder is only effective on through holes.

Depth Offsets

Safe Clearance

Specifies the axial or radial distance that the tool tip must maintain from the part. If the Safe Clearance value is larger than the Clearance Distance value, the tool always moves to the Vertical Clearance position between holes.

Clearance Distance (KF)

Specifies the distance at which the tool moves between holes when no collision is detected.

Clearance Distance defines each operational clearance point - typically, the point at which tool motion changes from either the rapid or engage feed rate to the cut feed rate.

You can enter a Distance value to be used between each hole top and its operational clearance point (RAPTO). Clearance Distance also represents the tool's closest approach to the Hole top between cutting operations.

Retract Distance (KF)

Retract Distance represents a distance measured along the tool axis. This distance runs from the hole top to the point where the tool retract move stops after feeding to the hole depth. Enter the value in the Retract Distance field.

Added Retract on Toolaxis Change (KF)

This allows you to define the distance the tool retracts when going from one hole to another when the second hole has a different tool axis than the first.

Rapto Offset (KF)

If turned on, and specified, Rapto Offset defines each operational rapto point. (A rapto point is the point at which tool motion changes from the rapid feed rate to the cut feed rate.) This is usually required if a hole is pre-drilled, in order to avoid cutting air.

You can enter a distance value to be used between each hole top and its rapto point. In the case of drill cycles, if no Rapto Offset is specified by the user, then the Clearance Distance value is used for that cycle's rapto value.

The KF parameter rapto_offset_toggle controls the Rapto Offset. Set it to 1 to turn on this option; set it to 0 to turn off the option and ignore any specified value within the rapto_offset parameter.

In Process Workpiece

The In Process Workpiece option has two settings: None and Use 3D.

When you select None, the default option, the system doesn't use an in process workpiece.

When you select Use 3D, the system adjusts the cycle RAPTO (clearance distance) and RTRCTO (retract distance) according to the current IPW. Also, if you select Collision Check and Use 3D for an operation, the collision check system references the current IPW for possible collision during transition moves.

During the vertical transition move, the move from a point high above the hole to the hole top, the collision is determined as follows:

  • If the tool or the holder collides with part or check geometry, then it is a collision.

  • If the holder collides with the IPW, then it is a collision.

All the IPW rules defined for Cavity Mill apply to Holemaking.

Collision Check

When selected, the software checks for collisions during the transition and approach moves and avoids the collisions. The software uses the following clearance related options when Collision Check is selected: Safe Clearance, Clearance Distance and Vertical Clearance.

A collision is any movement where the tool tip comes within the axial or radial Safe Clearance distance around the part. The tool tip moves to either the Clearance Distance or Vertical Clearance level to avoid the collision.

If there is a tool axis change between two holes, the operation does not perform a collision check. Instead, the tool retracts from the previous hole to the distance specified for the Added Retract on Toolaxis Change option before transitioning to the next hole.

When checking for collisions the system checks indefinitely in the direction of the hole axis for any collision during transition or approach. However, if a tool is short enough to traverse under an overhang condition and clear the part geometry then no collision is detected. If there is part geometry along the hole axis, the system reads this as a collision no matter how far the part geometry is from the feature being machined. Be aware of this when planning your program so that your program doesn't result in unmachined features.

If Collision Check is turned on with the Hole Depth Type set to Rule, and the Depth value is larger than the tool length, the hole will not be machined.

See also: Set the IPW precision for collision checking

Vertical Clearance (KF)

Specifies the distance from the part that the tool must move to between holes if a collision would occur at the Clearance Distance level.

This allows an additional retract between two holes when there is an obstacle between the two holes. Without this additional retract the tool would come close to the part.

Use User Defined Toolpath (KF)

If the software-generated tool path is not satisfactory, you can use this option to activate a user-defined tool path using linear and circular motions.

If this option is selected, the processor interprets any tool path defined within the user_defined_toolpath parameter in KF.
