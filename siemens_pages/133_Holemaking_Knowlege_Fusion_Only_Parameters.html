Holemaking Knowlege Fusion Only Parameters

Supressed

This Boolean parameter defines whether or not to suppress the Hole Mill or Holemaking operation. The operation is suppressed if this parameter is set to TRUE.

Use_model_depth

This Boolean parameter defines whether or not to use model depth on a feature.

Hole_top_output_type (KF)

This integer parameter controls the hole top position of a feature operation. If set to 1 the system moves the hole top along the hole axis to the current IPW surface in order to calculate the required cut depth from this point. This is useful for operations similar to center and spot drill when the cutting must take place on the IPW instead of the modeled feature.

Note:

 This only works if the In Process Workpiece option in the operation is active (Use 3d).

User_Defined_tool_path

This Boolean parameter is the gateway to user defined motions. From here users can call functions to create user defined motions instead of letting the processor use the standard system drilling cycles and motions. For each feature in a feature group, the motions are interpreted by the processor as linear and circular events in the tool path. Use the following to create motions and events:

  • ug_oper_createuserDefinedString()

  • ug_oper_createCircularMotion()

  • ug_oper_createLinearMotion()

Example: See DRILL_INTERRUPTED_SH operation in cam_sample_holemaking_udtp.prt in the ..\mach\sample folder.
