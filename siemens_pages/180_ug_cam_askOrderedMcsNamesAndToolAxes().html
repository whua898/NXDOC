ug_cam_askOrderedMcsNamesAndToolAxes()

  • ug_cam_askOrderedMcsNamesAndToolAxes()

    This function retrieves an ordered list of MCS names paired with their tool axes. The tool axis of an MCS is based on the tool axis parameter. If the Tool Axis option is set to All Axes, or if the Tool Axis option is not available, for example when you specify a turning or wire EDM MCS, the vector 0,0,0 is returned to indicate the axis is undefined.

    Sample input with the Tool Axis option set to All Axes.

    MCS_ALL_AXES

    MCS_SETUP11

    MCS_SETUP12

    MCS_SETUP2

    MCS_WEDM

    MCS_SPINDLE_TURN

    Sample output:

    Copy
    { {“MCS_ALL_AXES”,	Vector(0,0,0) },
      {“MCS_SETUP11”, 	Vector(0,0,-1) },
      {“MCS_SETUP12”, 	Vector(0,0,1)},
      {“MCS_SETUP2”, 		Vector(0,1,0)  },
      {“MCS_WEDM”,		Vector(0,0,0)  },
      {“MCS_SPINDLE_TURN”,	Vector(0,0,0)  }
