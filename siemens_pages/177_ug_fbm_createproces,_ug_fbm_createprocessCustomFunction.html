ug_fbm_createproces, ug_fbm_createprocessCustomFunction

The purpose is to create operations in a separate task (Create Process) from the feature group creation.

This function can only be used when operations are created through KF with a generic template. (Do not use one of the template variants supplied with the software.) The Create Process action is only available if a feature group is selected in the Feature Navigator and one of the following KF functions is available:

  • ug_fbm_createprocess

  • ug_fbm_createprocessCustomFunction

If both functions are found, ug_fbm_createprocessCustomFunction takes precedence.

Example of ug_fbm_createprocessCustomFunction

Defun: ug_fbm_createprocessCustomFunction
(
     Instance $instance
)
@{
  #ug_printValues( {"ug_fbm_createprocessCustomFunction", ""} );
  $process_type << self:fbm_process_type:;
   #ug_printValues( {"Process Type",$process_type });
  if $process_type = "CREATE_FEATURE_GROUPS" then
  @{  
    if member(ug_param_askFeatureName(self()),self:feature_types:) then ug_cam_create_process_from_excel_fbm() else true;
   }
   else true;
  #ug_oper_create( "hole_making","HOLE_MAKING","MY_HMOP","NONE","DRILL_METHOD" );
  TRUE;
} Boolean;
