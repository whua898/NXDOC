Create a new knowledge library

  1. Start Machining Knowledge Editor in native NX or in Teamcenter Integration.

  2. Choose File→New.

  3. In the NX Configuration Files dialog box, from the Configuration Folders list, select the location for the configuration file:

    • If you use a standard NX configuration, select UGII_CAM_CONFIG_DIR.

    • If you have custom configurations for your site, select UGII_CAM_CUSTOM_DIR.

    Note:

    You can also click Browse to select a configuration file from anywhere on the file system.

  4. From the Configuration Files list, select the same configuration that you also use in NX so that they are aligned. The standard NX configuration files used for machining knowledge are:

    • cam_general.dat

    • cam_native_rm_library.dat (for Teamcenter Integration)

  5. Select the unit system and click OK.

  6. Create your rules.

  7. Choose File→Save and save the new machining knowledge source file with a unique name.

    Example:

    my_machining_knowledge.xml

  8. In the \mach\resource\machining_knowledge folder, edit the machining_knowledge.dat file to point to the new machining knowledge library.

    This step is required for NX to access the new machining knowledge library and create geometry from the features.

    Example: 

    MACHINING_KNOWLEDGE_LIBRARY,${UGII_CAM_MACHINING_KNOWLEDGE_DIR} my_machining_knowledge

    If you use Teamcenter Integration, edit the machining_knowledge_part_planner.dat file to point to the new item revision.

    Example: 

    @DB/my_machining_knowledge/A
