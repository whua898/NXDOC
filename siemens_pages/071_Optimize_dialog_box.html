Optimize dialog box

The options in the Optimization dialog are the following: Consolidates Tool, Minimize Tool Changes, and Create Optimized_NC Group. Below is an explanation of each option.

Consolidate Tools

Tells the system to reapply the tool query, and look through the lists of retrieved tools that have been selected for this NC program. It finds the tools that are common throughout all the operations. This reduces the number of tools that are used in the NC program. Having your tools consolidated minimizes tool changes and tool cost, creating a more efficient NC program.

Minimize Tool Changes

Organizes the operation into the order that creates the least amount of tool changes by reordering the operations that use the same tool.

Create Optimized_NC Group

Creates an Optimized_NC group. The tool path can be generated, further optimized and stored in this group.
