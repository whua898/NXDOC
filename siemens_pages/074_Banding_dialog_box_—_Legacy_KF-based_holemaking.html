Banding dialog box — Legacy KF-based holemaking

The Banding dialog box displays when you select Banding in the Feature Resequence section of the Optimized_NC dialog.

Band Direction

Horizontal

Allows you to define a series of horizontal bands to contain and direct a zig-zag tool motion parallel to the work coordinate XC axis. The bands are defined by pairs of horizontal lines, and are sequenced in the order they are defined.

Vertical

Vertical is the same as Optimize by Horizontal, except that the bands are parallel to the work coordinate YC axis and the points in each band are sequenced according to YC coordinates.

Sequence

Ascending

An ascending band goes from minimum XC values to maximum XC values within the band.

Descending

A descending band goes from maximum XC value to minimum XC value within the band.

Edit Band

Append

Select this option if you want to append a band. Then select the Append button to add the band.

Remove

Select this option if you want to remove a band. Then select the Remove button to remove the band.

Append/Remove

This button switches back and forth between Append and Remove, depending on the option that is selected beneath Edit Band. This button is then used to execute the option that has been selected in Edit Band.

Left and Right Arrows

The left and right arrows allow you to cycle through all the bands until you come to band you want to select.

Remove All

This button removes all the bands that have been created.

Resequence

The Resequence button executes the banding optimization based on the options and bands you have selected in the dialog.  It displays the order in which the features will be machined, by placing a number on each feature.
