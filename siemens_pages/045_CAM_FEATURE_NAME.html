CAM_FEATURE_NAME

Every tagged entity needs to have a minimum set of attributes to make it a valid candidate for the Holemaking process. The first attribute it must have for identification is the attribute CAM_FEATURE_NAME. This attribute gives the tagged entity a title that the CAM system can understand. Below are the values that come with the system for this attribute.

Values for CAM_FEATURE_NAME:

SIMPLE_HOLE

COUNTER_BORE_HOLE

COUNTER_SUNK_HOLE

THREADED_SIMPLE_HOLE

THREADED_COUNTER_BORE_HOLE

THREADED_COUNTER_SUNK_HOLE

SYMBOLIC_THREAD

The values above are currently used in the Holemaking template. CAM_FEATURE_NAME may also have other values, these are called User Defined Attribute (UDA) features. You must enter these UDA features and represent them in the Holemaking template to be used as values for CAM_FEATURE_NAME.
