ug_oper_hasFeatureAttribute()

This function asks whether or not the feature has an attribute or parameter with this name. If it does it returns TRUE. If it does not, it returns FALSE. This can be used prior to ug_oper_askFeatureValue to make sure this attribute exists.

Examples of How to Use ug_oper_hasFeatureAttribute()

Copy
if ug_oper_hasFeatureAttribute("Tolerance") = TRUE then
  ug_oper_askFeatureValue("Tolerance") else 0

This example asks for the feature's tolerance value only, if it has one.

Copy
 
if ug_oper_hasFeatureAttribute("Diameter") = TRUE then
   ug_oper_askFeatureValue("Diameter") 
else if ug_oper_hasFeatureAttribute("Hole Diameter") = TRUE then
   ug_oper_askFeatureValue("Hole Diameter") else 0

This example asks for the feature's tolerance value only if this attribute or parameter exists.
