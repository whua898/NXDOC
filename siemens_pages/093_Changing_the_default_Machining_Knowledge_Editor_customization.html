Changing the default Machining Knowledge Editor customization

Machining Knowledge Editor customization is determined by the following files:

  • The manufacturing configuration files, which determine the available tools, machines, materials , and operation type templates.

    The default location for manufacturing configuration files is the UGII_CAM_CONFIG_DIR folder.

    If you have a custom directory structure, configuration files are in the UGII_CAM_CUSTOM_DIR folder.

  • The customization_base.xml file, which determines the available feature types and operation parameters.

    The customization_base.xml file is located in the UGII_CAM_BASE_DIR\machining_knowledge_editor\data folder.

    If you have a custom directory structure, customization_base.xml is in the UGII_CAM_CUSTOM_DIR folder.

    Warning:

    The customization_base.xml file is a system file. Do not modify the customization_base.xml file.

When you create a new machining knowledge source file, the Machining Knowledge Editor reads the customization_base.xml file and adds standard customization settings.

To update the customization for an existing machining knowledge source file, choose View→Options→Update Upon Load. The Machining Knowledge Editor reads the customization_base.xml file and updates the standard customization settings each time you open the machining knowledge source.

View and modify the Machining Knowledge Editor customization

  1. Open the machining knowledge source file.

  2. Choose View→Customization.

    The Machining Knowledge Editor Customization view is displayed.

    You can add a new class or attribute. You can edit or remove a user-defined class or attribute. You cannot edit or remove a system-defined class or attribute.

For details on customizing the Machining Knowledge Editor, see the Customization View chapter in the MachiningKnowledgeEditor.pdf Help file.
