FBM Geom options

Feature Type

Feature Type list

Lists the feature types available in the selected geometry parent (for example, the workpiece).

Note:

When you change the Feature Type all the operations in the current group are deleted.

Classification Criteria

The Classification Criteria field shows all the attributes of the selected feature in the Feature Type. Check one or more of the attributes to be used as the classification criteria. These attributes come from: KF attributes, feature expressions, and UDAs.

Once you have selected the attributes, the status line tells you how many groups have been found.

Move your cursor into the Graphics Window to select a group. When your cursor moves over a feature, the entire group that the feature belongs to is highlighted. Click to select the group you want.

Select Features

Lets you select features.

Reclassify

Lets you delete the group and classify the features again. The features are classified based on the currently selected criteria and accessibility vectors.

Feature Selection

Select Features

Accesses the Feature Selection dialog box to let you add or delete features.

Accessibility Vectors

Accesses the Accessibility Vectors dialog box to let you specify the direction from which the features can be machined.

If the tool axis defined in the parent MCS geometry group matches any of the accessibility vectors specified for a feature, the feature is included in the feature group.

If the tool axis in the MCS group is set to All Axes then all the features, regardless of their accessibility vectors, are included in the group.

You use the Feature Group Dialog to create or edit a feature group. The dialog has items to customize for feature identification, classification, reclassification, selection, and accessibility.
