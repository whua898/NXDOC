Machining Knowledge Editor

The Machining Knowledge Editor (MKE) is a stand-alone application used by your company's knowledge engineer to create and modify the rule libraries. MKE enables the definition of manufacturing rules required to machine features. You can use the MKE to:

  • Create and modify machining rule libraries.

  • Define in-process features.

  • Define alternative processes to use when the tool required for the preferred process is not available.

  • Create rule-based operations for all milling strategies, including planar milling, contour milling, and multi-axis milling.

The machining knowledge source file contains two major parts:

  • The customization area with the available rule components:

    • Feature, operation, and tool types

    • Machines

    • Part materials

  • The library of rules. Each machining rule:

    • Defines an operation or operation class.

    • Has a name and a priority.

    • Requires a tool.

    • Takes a less worked feature (lwf) as input and produces a more worked feature (mwf).

    • Overrides the NX template parameters.

If the machining knowledge library is modified after it is used to create operations in NX, the old operations must be deleted and the geometry groups re-created.

The way the MKE interacts with NX depends on how you set the options within MKE.

See the Machining Knowledge Editor online Help for more information on this application.
