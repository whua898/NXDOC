Find Features options

Type

Type

Feature Identification

Finds existing model features and User Defined Features (UDFs).

Parametric Recognition

Finds features by analyzing the geometry and does not require a feature-based model. Parametric features are described by their parameters. This is the preferred type of recognition.

Legacy Hole Recognition

Finds the legacy Holemaking feature types and User Defined Feature hole types.

Legacy Face and Pocket Recognition

Finds the legacy Face and Pocket non-parametric feature types.

Manual Recognition

Lets you control feature selection by manually specifying features and their faces when the automatic methods do not produce the desired result. Only manually recognized features can be edited by adding or removing faces.

Geometry to Search

Available for all recognition types except Manual Recognition.

Search Method

Lets you select the body or bodies to search.

All Geometry

Searches all bodies.

Workpiece

Searches the geometry specified in the Workpiece geometry group.

Specify

Lets you select the body to search from the graphics window.

Select Geometry

Lets you select one or more solid or sheet bodies to search for features.

Features to Identify, Features to Recognize

Available for all recognition types except Manual Recognition.

Features to Identify list

Lets you select the CAD and user-defined features to identify from a list of available feature types.

Features to Recognize list

Lets you select the features to recognize from a list of available features.

  • For Parametric Feature Recognition and Legacy Hole Recognition, when you first open the dialog box the check boxes for all features are selected. The features you select remain selected until you change them.

  • For Legacy Face and Pocket Recognition, you can only select one feature type each time you recognize features.

Map Features

Maps found features and their parameters to other feature types. When you select this option, the mapped feature types are added to the Features to Recognize list. Mapping knowledge is provided for the hole feature types.

Feature mapping knowledge is customizable, so that you can create feature mapping to feature types that are important for you.

Tip:

The mapping mechanism can serve to merge your company's existing feature-based machining technologies with the rule-based approach in this software.

Use Feature Name as Type

Available for Feature Identification only.

Assigns the identified feature's name as its feature type.

Machining Access Direction

Available for all recognition types except Manual Recognition.

Specify Vector

Lets you limit the features recognized to ones that are accessed from the specified direction.

Limit Search Area

Available for Feature Identification, Parametric Feature Recognition, and Legacy Hole Recognition only.

Select Face

Lets you select the faces on which to perform the recognition. You must select at least one face of a feature for NX to recognize it. For more complex features, the more faces you select, the better the chances that NX will recognize each feature correctly.

Tip:

Use the Face Rule list on the Top Border Bar to help you select faces. For example, to recognize all of the holes on a face, set the Face Rule list to Adjacent Faces before you select the face.

Define Floor

Available for Legacy Face and Pocket Recognition only.

Select Face

Lets you select the faces above which you want to search for features.

Feature Settings

Available for all recognition types except Manual Recognition.

Assign Color Attribute

Assigns a color attribute to the identified feature if it includes faces that are a different color than the body, and all these faces have the same color.

Add Modeling Feature Attributes

Adds the following attributes the feature if they are available in the modeled feature.

  • PMI dimension tolerances and surface finish.

  • Edge or face names.

  • Edge or face attributes.

Recognized Features

Find Features

Not available for Manual Recognition.

Starts the feature search.

Recognized Features list

Lists the features found. Selected features are highlighted in the graphics region.

Manual Recognition options

Recognized Features

The Features list box displays the specified features with counts of their floor and wall faces, and allows deleting and editing of features.

Feature Type

Lets you select the name of the feature. Press Enter or Tab to save the name to the feature.

Select Floor face

Lets you select faces to define the floor of the feature.

Select Wall Face

Lets you select faces to define the walls of the feature.

Define Feature

Creates a new feature in the list.

Tip:

To edit an existing feature, click on the row. You can then modify the face selections for this feature.

Delete

Deletes the currently selected feature.
