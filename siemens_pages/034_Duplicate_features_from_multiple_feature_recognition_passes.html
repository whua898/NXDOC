Duplicate features from multiple feature recognition passes

When you run feature recognition in multiple passes, NX does not duplicate a feature in subsequent passes as long as it completely recognizes the feature in a previous pass. However, NX does duplicate a feature if it was only partially recognized in the previous passes. This is because NX identifies two features as duplicates only when there is 100% overlap in the faces.

The following example shows the results from two passes of feature recognition. One pass is from the top side of a plate, and one pass is from the bottom side of the plate.

Example: Duplicate features

For this workflow, you want to machine only the counterbore from the top. NX recognizes a STEP1POCKET feature.

First pass settings

Result

STEP1POCKET

All other step hole features.

You then want to machine any remaining hole volume from the bottom. NX recognizes a complete STEP3HOLE1 feature because there is only partial overlap with the previously recognized feature.

Second pass settings

Result

All step hole features.

Solution

In the Find Features dialog box, in the Features to Recognize group, clear the check box for each feature you need to avoid duplicating.

Second pass settings

Result

STEP2HOLE

STEP3HOLE1
