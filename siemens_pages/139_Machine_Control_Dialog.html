Machine Control Dialog

Machine control allows you to control whether circular or B-Spline (NURBS) tool motions are allowed to be in the tool path, to specify postprocessor commands in the tool path, and to provide cutter compensation information in the tool path.

Motion Output

Many machine controllers allow you to move the tool along a true circular path or along a rational B-spline curve (NURBS). Motion output allows you to choose whether potential circular tool motions or NURBS will be included in your tool path. When you use this option, either the system converts a series of linear moves to a single circular move or it converts linear/circular moves to a rational B-spline curve, if enough of the GOTO points lie on the same arc.

Motion Output gives you four options to select from in the drop down menu: Linear Only, Circular Perp to TA, Circular Perp/par to TA and NURBS.

For more information on these options go to Manufacturing General-→ Common Operation Options-→ Machine Control-→ Motion Output.

Startup Commands

Startup commands allows you to specify startup post commands for the operation by using a previously defined set of parameters or specifying a new set. You may check this option on or clear this option off.

Retrieve

Retrieve allows you to choose a previously defined set of startup post commands from an existing operation or template.

Edit

Edit takes you to the Startup Post Commands dialog which allows you to define a set of startup post commands.

End-Of-Path Commands

End-of-path commands allows you to specify End-of-path post commands for the operation by using a previously defined set of parameters or specifying a new set. You may check this option on or clear this option off.

Retrieve

Retrieve allows you to choose a previously defined set of end-of-path commands from an existing operation or template.

Edit

Edit takes you to the End-of-Path Commands dialog which allows you to define a set of end-of-path post commands.

For more information on startup commands or end-of-path commands go to Manufacturing General-→ Common Operation Options-→ Machine Control Events (Postprocessor Commands)-→ Startup Commands or End-of-Path Commands.
