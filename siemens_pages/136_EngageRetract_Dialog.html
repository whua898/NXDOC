Engage/Retract Dialog

The Engage/Retract option allows you to define the proper tool motions to engage and retract from the hole.

Horizontal (KF)

This is the horizontal clearance distance applied to the wall during engage.

Vertical (KF)

This is the vertical clearance distance added to the hole top. This is also used as the vertical clearance during the collision avoidance. The vertical clearance also indicates the distance above the cutting plane at which the tool should stop its approach move and begin its engage move.

Minimum

Enter the minimum clearance distance in the Minimum field. Minimum clearance is used when the clearance plane is not used. It allows you to set the clearance (the minimum distance between the tool and the floor plane) at the start and/or the end of cutting a hole.

Transfer Methods

Enter a value in the Transfer Method field to specify the level to which the tool retracts during transfer moves within a hole. The cutter first moves from its current position to the specified plane. The transfer move then occurs at the level of the specified plane to a position above the start of the engage move. Finally, the cutter moves from the specified plane to the start of the engage.

For more information see Transfer Method at the: Manufacturing Milling-→Planar and Cavity Milling-→ Engage and Retract-→ Method-→ Transfer Method.
