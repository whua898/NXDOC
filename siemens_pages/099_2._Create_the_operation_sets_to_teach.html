2. Create the operation sets to teach

We will use the 4 holes to the right of the dovetail slot to create the following operation sets:

  • STANDARD_HOLE_DRILL_TO_SIZE to drill a hole to size when the matching drill is available.

  • STANDARD_HOLE_MILL_TO_SIZE to drill a hole, then mill it to size when a matching drill is not available.

  • TOLERANCED_HOLE_BORE to drill a hole, then bore it to tolerance.

  • TOLERANCED_HOLE_REAM to drill a hole, then bore, then ream to tolerance.

  1. Right-click in the background of the Machining Feature Navigator and choose Find Features.

  2. Set the following:

    Type group

    • List = Parametric Recognition

    Geometry to Search group

    • Search Method = All Geometry

    Features to Recognize group

    • Map Features =

    • Mapping→STANDARD_HOLE =

    • Mapping→TOLERANCED_HOLE =

    • Recognition =

    Machining Access Direction group

    • Method = None

    Feature Settings group

    • Assign Color Attribute =

  3. In the Recognized Features group, click Find Features .

  4. Click OK.
