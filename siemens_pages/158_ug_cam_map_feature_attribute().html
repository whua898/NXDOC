ug_cam_map_feature_attribute()

This function generalizes feature parameters or attributes by using a synonym key word. If the features parameters or attributes to be used have distinct names but same meanings they can be put in a list which is assigned to the key word that represents the attributes name. The key words corresponds to the segments of the feature. For example dia1 is the synonym key for the first diameter on a hole relative to the hole top. Dia2 would represent the 2nd diameter, depth1 the first depth, depth2 the second, and so on. This allows you to use these synonyms without having to know the real name of the attribute.  

Example:

top_diameter << ug_oper_askFeatureAttributeValue("ug_cam_map_feature_attribute("dia1", Number));

If this is called at the operation level it will return the most top diameter value of the active feature if it is listed in the function (dfa) and has the "dia1" key word defined as a representative of its original parameter/attribute name.

Example from ug_cam_map_feature_attribute():

#Key word DIA1 for Counterbore Hole, Cap Screw Hole, etc.
{{"DIA1","C-Bore Diameter","CB_dia"}
#Key word DIA1 for  Simple Hole, Threads, etc. {{"DIA1","Diameter","Tapped Drill Size","Hole_diameter","thread_tapped_drill_size"}
