Create a new knowledge library based on the one supplied

  1. Start Machining Knowledge Editor in native NX or in Teamcenter Integration.

  2. Choose File→Open and select the supplied machining knowledge source file from your local folder or from Teamcenter.

  3. Choose File→Save As. Save the machining knowledge source file with a new name.

    Example:

    my_machining_knowledge.xml

  4. Create or edit your rules.

  5. Choose File→Save.

  6. In the \mach\resource\machining_knowledge folder, edit the machining_knowledge.dat file to point to the new machining knowledge library.

    This step is required for NX to access the new machining knowledge library and create geometry from the features.

    Example: 

    MACHINING_KNOWLEDGE_LIBRARY,${UGII_CAM_MACHINING_KNOWLEDGE_DIR} my_machining_knowledge

    If you use Teamcenter Integration, edit the machining_knowledge_part_planner.dat file to point to the new item revision.

    Example: 

    @DB/my_machining_knowledge/A
