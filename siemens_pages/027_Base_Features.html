Base Features

The modeling application in NX provides standard hole pocket and slot features such as RECTANGULAR_POCKET, and CYLINDRICAL_POCKET. The appearance of the final model depends on how the base features were applied. For instance, two intersecting RECTANGULAR_POCKETS can form one pocket or an open pocket, or even just a flat face with no walls. Feature identification and processing requires predefined strategies to machine the resulting feature. For example, open and closed pockets may both use the same RECTANGULAR_POCKETS NX feature, but each has a different machining process.

If a model contains base features, the feature-based machining module identifies and evaluates these features. The software can then add them into feature groups based on their feature name and parameters.

Feature-Based Milling Features and Parameters

Feature

Parameter

POCKET

Length X, Length Y, Length Z, Corner Radius, Floor Radius, and Taper Angle.

Note:

Note that modeling pockets are named RECTANGULAR_POCKET, while in Feature-Based Milling they are named POCKET.

Note:

With the manufacturing preference Display Selected Objects on if you select multiple FBM Feature Groups the no features are displayed. If you select a single group that feature is displayed and if you select the operations in multiple Feature Groups they are all displayed.

This is not specific to feature groups, geometry groups and tools have the same behavior.
