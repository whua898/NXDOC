Recognized parametric feature types

The vectors D, L, and W define the depth, length, and width direction of machining features.

  • For all features, the ORIENTATION_D parameters define the direction to measure depth.

  • For milling features like pockets and slots, the ORIENTATION_L parameters define the direction to measure length, which is perpendicular to the depth. For rotatory symmetrical features like holes, length has no meaning.

  • For milling features like pockets and slots, the width is perpendicular to the length and the depth.


When you select a machining feature, NX displays an arrow to represent the depth vector (1).


The feature also has a position, which NX displays using the feature coordinate system (2). The positive Z-axis of the feature CSYS is in the opposite direction of the depth vector.
