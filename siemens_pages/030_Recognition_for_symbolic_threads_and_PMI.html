Recognition for symbolic threads and PMI

Only the Parametric Recognition option reads and interprets PMI data.

NX recognizes symbolic threads and can extract the thread attributes. The recognition fails if:

  • A symbolic thread is not found where one is expected on a feature. For example, a symbolic thread was present during feature teaching, but is not present during feature recognition.

  • There are multiple threads on a single feature.

Manufacturing features update in a part or assembly when the thread data or other PMI data attached to one of the feature faces or edges is changed or deleted.

Copying threads for wave linked models

The environment variable UGII_CAM_FBM_PMI_FROM_WAVE is not supported. To copy threads for wave linked models in your FBM process, you must do the following:

In the WAVE Geometry Linker dialog box, in the Settings group, select the Copy Threads check box.

If you do not select this check box:

  • When you use the Find Features command, NX does not find threaded machining features.

  • When you update an FBM process created in previous NX versions using the UGII_CAM_FBM_PMI_FROM_WAVE environment variable, NX deletes any existing threaded machining features.
