Teach Feature Mapping dialog box

Feature Type Mappings group

Select Input Type

Lists the feature types that are currently available in the machining knowledge library. You select the feature type for NX to recognize.

Select Output Type

Displays the available feature types in a hierarchy.

When you add a new feature type, it becomes a subset of the selected feature type. For the following example hierarchy, you would add a mapping rule so that NX creates a STEP1HOLE_PMI feature only when it finds a STEP1HOLE feature that also has PMI assigned.

Example:

STEP1HOLE
STEP1HOLE_PMI

 

Add New Type

Adds a new feature type to the Select Output Type hierarchy list.

Select Rule

Displays the list of available mapping rules.

Example:

Mapping
MAP_S1H_PMI
MAP_S1H_COLOR

Add New Rule

You must select the Mapping node to add a new mapping rule.

Conditions tab

Parameters

You do not have to copy your input parameters to your output parameters. NX does this for you automatically.

Objects

Lists the object for which you can apply conditions. Select the in object to specify your input conditions. Select the out object to specify conditions for the feature you are mapping to.

Parameters

Lists the available parameters. Select a parameter name to add it to your mapping condition.

Functions

Available when you click the Fx button in the Operators group.

Lists the available functions. Select a function name to add it to your mapping condition.

Operators

Includes commonly used operators. Click an operator to add it to your mapping rule condition. Click the < > operator to add a not equal condition. Click the Fx operator to make the Functions list available in the Parameters group.

Conditions

Edit Condition

Displays the text for the condition you are currently editing.

Note:

  • You must enter values less than 1 with a leading zero.

    For example, if you enter .5, NX displays a syntax error message. You must enter 0.5.

  • You must add a space before and after the operators - and +.

Validates the condition in the Edit Condition box. Moves the condition to the Mapping Conditions box, or displays an error message if there is a syntax error.

Mapping Conditions

Displays all of the conditions for the selected mapping rule. To modify an existing condition, select it in the Mapping Conditions box, then make your changes in the Edit Condition box.

More tab

Mapping Rule

Priority

Specifies the priority to assign to the mapping rule selected on the Conditions tab.

It is important to assign a priority rule because NX uses the priority together with the conditions to determine which mapping rule to apply. A larger priority number indicates a higher priority.

If you do not assign a priority, NX applies the first rule, in random order, which has all of its conditions satisfied.

Create Mapping Rule group

Teach Mapping Rule

Available after you define the conditions for a mapping rule.

Generates the new or modified mapping rule to store in the mapping rule library.

OK, Apply

Available when you have write permissions to the machining knowledge library.

Saves the new or modified mapping rule in the machining knowledge library specified in the UGII_CAM_MACHINING_KNOWLEDGE_DIR environment variable.
