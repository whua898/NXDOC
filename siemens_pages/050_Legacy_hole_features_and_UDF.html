Legacy hole features and UDF

You can modify the existing recognition definition or add a new definition for features that are symmetric about a rotation axis. These definitions are stored in the feature_definitions.def file located at MACH\resource\feature. The default file includes definitions for the legacy manufacturing features counter_bore_hole, counter_sunk_hole, and simple_hole.

Note:

NX does not include PMI data when recognizing features defined in the feature_definitions.def file.

Hole recognition is based on these geometry elements: cylindrical, conical, planar, and torus faces. The base elements are listed within the feature_definitions.def file to describe the hole features.

Combined Compound Hole example

You can recognize compound blind and compound through holes together as one type of hole, the compound hole.

  1. CYL

  2. PLANE

  3. CYL

  4. PLANE

  5. CYL

  6. PLANE

Compound through and compound blind holes.

 The definition will be as follows:

Copy
# definition of a compound hole
    FEATURE COMPOUND_HOLE
    {
        CYL
        PLANE 
  CYL
        PLANE
        CYL
        PLANE /?  # 0 or 1 plane
    }

This definition specifies that the topmost face of the feature must be cylindrical, and the connecting faces must be planar, then cylindrical, then planar, then cylindrical. The last face is planar and the qualifier "/?" indicates that there can be 0 or 1 planar face.

When there is no planar face the definition will match that of the compound through hole and when there is one planar face the definition will match that of the compound blind hole.
