ug_oper_askLibrefOfLibObject()

This function returns the library reference of the specified library object.

The library object is indicated by the input libobject key which is one of the listed below.

This function only works in the context of an operation. If the specified object is not a library object the return value will be an empty string.

Libobject keys are: "TOOL_MATERIAL"

        "PART_MATERIAL"

        "CUT_METHOD"

        "MACHINE"

        "TOOL"

Note:
