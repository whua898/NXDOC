Cutter Compensation

The Cutter Compensation option gives you three options: Inactive, Engage/Retract or Wall.

Inactive

The Inactive option indicates that no cutcom commands are generated in the tool path.

Engage/Retract

The Engage/Retract option indicates that cutcom is to be applied with engage and retract moves within the Activation Range. If the cutcom option is set to Engage/Retract, Minimum Move and Minimum Angle become active in the dialog, and their values are output along with the cutcom statement. When Engage/Retract is selected, Register Number and Output Plane are available.

Wall

The Wall option causes cutcom output only when the tool contacts the part wall. Cutcom is active just before the tool motion to the wall and inactive just before the tool motion away from the wall. Cutcom is suppressed during interior passes. When Wall is selected, Register Number and Output Plane are available while Minimum Move and Minimum Angle are not available.

Minimum Move

Minimum move applies to automatic engage and retract moves only. The minimum move is a specified distance away from the start of a circular engage along a specified minimum angle.

Minimum Angle

Minimum angle applies to automatic engage and retract moves only. It is the specified angle rotated from the linear extension of the arc radius.

Output Register Number

Check Output Register Number on to indicate whether the cutcom command includes a register number. The register number is an optional part of the cutcom command.

Register Number

Register number is an integer number that indicates which controller register should be activated with the cutcom command.

Output Plane

Check Output Plane on to indicate that you want to include plane data in the cutcom command. The plane inserted into the cutcom command is the plane where cutter compensation is applied.

Note:

CAUTION: Cutter compensation options work independently from the cutter compensation listed under startup commands. If both are set, both appear in the tool path and CLSF, which may be undesirable.
