Tagging Attributes to Points, Arcs and Faces Dialogs

These tagging dialogs are used to tag manufacturing attributes to points, arcs and faces. The common options among these three dialogs are explained below.

Feature Name

The first option in the dialog is Feature Name. This option has a drop down list that contains all the feature names that can be used. If you select a feature name, the following items change:

Feature Description

This field contains a brief description of the feature selected in the Feature Name field.

Feature Templates

This field includes the default value sets of the feature selected in the Feature Name field.

Filter and Hole Axis for Arcs and Faces

Class Selection

Click this button to display the Class Selection dialog. This dialog allows you to select specific geometric entities depending on the tagging dialog you have selected.

Hole Axis

Vector Method

Click this button to display the Vector Method dialog. This dialog allows you to select an axis for all the selected entities.

Dialog Attributes

The attributes that are listed in each dialog depend on the Feature Name that has been selected. For a description of the 24 attributes that are delivered with the system go to the Classification Attributes List section. Keep in mind it is also possible to customize more attributes. Therefore, if the attribute you are looking for was customized into the system, it is not in the chart.
