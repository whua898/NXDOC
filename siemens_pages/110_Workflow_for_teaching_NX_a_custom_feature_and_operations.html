Workflow for teaching NX a custom feature and operations

Use the following workflow to define your own feature types and machining rules without manually writing the feature recognition code.

  1. (Optional) In the Machining Knowledge Editor, create a new empty library for your custom recognition rules.

    It is preferable to store your custom recognition rules in a separate library.

  2. In NX, fully define the custom feature that you want to teach NX to recognize.

    Examples of feature types include holes, slots, faces, and complex custom features.

    Note:

    It is preferable to define the custom feature in a separate part that is used only for teaching so that you can add attributes that are not valid for your production environment. For example, the feature may have PMI dimensions that are only used to teach the recognition rules.

  3. Use the Teach Features command to define parametric recognition rules for your new custom feature types.

    The command stores the parametric recognition rules in a machining knowledge library.

  4. Use the Teach Operation Sets command to automatically generate new machining rules from existing operations within Manufacturing.

    The command stores the machining rules in a machining knowledge library.

  5. In NX, use the Create Feature Process command to create the same set of operations for your custom feature in all of your parts.
