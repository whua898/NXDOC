Teaching NX how to machine your features

You can teach NX your company's requirements for machining specific feature types without having to learn the FBM reasoning process. Examples of feature types include holes, slots, faces, and complex custom features.

For the most control over the process, limit write permissions to the machining knowledge library. A machining knowledge expert fully defines the conditions for your features so that the CAM programmer can automatically create operation sets for selected features. For more flexibility, or if it is difficult to standardize processes, give CAM programmers write permissions to the machining knowledge library. Programmers can then define the conditions that are necessary to establish your company's best practices, and choose which operation set to create for a selected feature type.
