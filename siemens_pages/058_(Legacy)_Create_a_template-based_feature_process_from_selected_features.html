(Legacy) Create a template-based feature process from selected features

This example shows how to create operations, tool groups, geometry, and methods for simple holes.

  1. In the Machining Feature Navigator palette, select the SIMPLE_HOLE features.

    Press and hold Ctrl or Shift to select multiple features.

  2. Right-click the selected features and choose Create Feature Process.

  3. (Optional) Specify the template to use for creating your operations.

    For this example, select hole_making.

  4. Specify the process that you want to create.

    • In the Process Type group, select SIMPLE_HOLE.

  5. Specify the geometry parent.

    • In the Location group, from the Geometry list, select WORKPIECE.

    You can also select Automatic.

  6. Specify how to create the feature process.

    • In the Settings group, from the Groups list, select Use Existing.

    The software reuses existing feature processes, or creates a new process if an existing process is not available.

  7. Click OK.

    To create the machining process, NX does the following:

    • It creates the appropriate operations for each feature.

    • It selects or retrieves tools for the operations.

    • It sets the tool, program, and geometry parents for the operations.

    • It merges features with identical processes into geometry groups.
