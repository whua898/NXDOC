Hole Mill options

Note:

In the Holemaking dialog and Hole Mill dialog documentation there are many parameters with (KF) in their name. This means that these parameters can be defined in both a dialog and the KF rule. When defining these parameters the system takes the information that you enter last. For example, if you define a KF rule for a parameter and then later define this same parameter in a dialog, the system takes the information you have entered in the dialog. If you first enter the information in the dialog, and then write a KF rule for this parameter, the system takes the KF rule

See Common operation options for common options not described here.

Specify Hole Top

The hole top is where the cutting tool enters the hole as it begins to machine the hole.  

Defining The Hole Top

Select the Hole Top icon from the HOLE_MILL dialog.

  • If the hole top has not yet been selected click the Select button.

  • If the hole top has been selected and you would like to edit or reselect your choice, select the Edit or Reselect button.

This displays the Hole Top dialog.

When specifying the hole top one of the features in the feature geometry group under which the operation sits is presented for selection. Specifying the hole top for this feature is enough to satisfy the hole top specification for all the features in this feature type. This is because all the features in this feature type are identical, based on the selected classification criteria, and the hole top can be mapped to all features in this feature type.

Specify Hole Axis

The hole axis defines the tool axis to machine the hole.

Defining the Hole Axis

There are three ways to define the Hole Axis: Vector, Rule, and Rule if no Vector.

Select the Hole Axis icon.

  • If the hole axis has not yet been selected click the Select button.

  • If the hole axis has been selected and you would like to edit or reselect your choice, select the Edit or Reselect button.

This displays the Hole Axis dialog.

When specifying the hole axis with a smart point, one of the features in the feature geometry group under which the operation sits is presented for selection. Specifying the hole axis for this feature is enough to satisfy the hole axis specification for all the features in this feature type. This is because all the features in this feature type are identical, based on the selected classification criteria, and the hole axis can be mapped to all features in this feature type.

Specify Hole Depth

There are two ways to define Hole Depth: Smart Point and Depth/Rule.

In this dialog you define Hole Depth by using a Smart Point.

Defining Hole Depth

Select the Hole Depth icon.

  • If the hole depth has not yet been selected chose the Select button.

  • If the hole depth has been selected and you would like to edit or reselect your choice, select the Edit or Reselect button.

This displays the Hole Depth Dialog.

When specifying the hole depth with a Smart Point, one of the features in the feature geometry group under which the operation sits is presented for selection. Specifying the hole depth for this feature is enough to satisfy the hole depth specification for all the features in this feature type. This is because all the features in this feature type are identical, based on the selected classification criteria, and the hole depth can be mapped to all of them.

Cut Method

Cut types in hole mill operations determine the tool path pattern used to machine cut regions. The following cut types are available for Hole Mill operations: spiral and helical.

Spiral

The spiral cut pattern cuts one level at a time in a spiral pattern beginning in the center of the hole, and ending when it has reached the wall. Then it makes one more circular pass along the wall of the hole.

When a predrill diameter is defined to be larger than the tool diameter, the spiral cut pattern begins at a point on the wall of the predrilled hole.

  1. The green circle is the edge of the hole you are cutting.

  2. The blue outer circle is the wall clean up cutting move.

  3. The red line is the rapid move.

  4. The yellow curve is the engage move.

  5. The dotted white line is the retract move at rapid speed.

  6. The blue arc  is the retract move at the cutting speed.

  7. The blue spiral is the cutting move.

Helical

The helical cut pattern goes along the wall of the hole in a continually downward motion, until it reaches the bottom of the hole or the bottom of the level. When it reaches the bottom of the level it makes one more circular pass along the wall of the hole.

  1. The yellow line is the engage move.

  2. The solid green line is the part.

  3. The dotted green line is the part.

  4. The blue helix is the cutting move.

  5. The bottom blue circle is the bottom clean up cutting move.

Stepover (KF)

Stepover allows you to specify the distance between cut passes. For more information about stepover go to Manufacturing Milling-→ Planar and Cavity Milling-→ Frequently Used Options-→ Stepover.

Distance/Height/Percent (KF)

The text field located just below the Stepover option requires a distance, height, or percent value depending on the selected stepover method. For more information about stepover go to Manufacturing Milling-→ Planar and Cavity Milling-→ Frequently Used Options-→ Stepover.

Hole Diameter (KF)

The Hole Diameter is the diameter to be milled. Enter the value in this field if the value of the hole diameter is greater than zero. If the diameter is less than zero, use the diameter of the hole top entity.  

Predrill Hole Diameter (KF)

The Predrill Hole Diameter is the diameter of a pre-drilled hole. Use this option if the hole being machined is predrilled.

Part Stock

This is the stock added to the diameter of the hole, either implied by the geometry or specified by the parameter.

Part stock is the amount of material remaining on the walls of the hole after it has been machined.

Maximum

The Maximum option in Hole Mill is the same as the Maximum option in Planar Mill. The only exception is that the depth per cut is not adjusted. Therefore, the last cut may be less than the depth per cut.

Added Retract on Tool Axis Change (KF)

This allows you to define the distance the tool retracts when going from one hole to another when the second hole has a different tool axis than the first.

Cut Feed

The Cut Feed field allows you to specify the feed rate for tool movement while the cutter is in contact with the part geometry.

Retract Distance

Retract distance represents a distance measured along the tool axis, from the hole top to a point to which the tool retracts, after feeding to the hole depth. Enter the value in the Retract Distance field.

The tool retracts the distance of the value entered. It is measured from the hole top. If the value is zero, then the tool does not retract, and may stay at the bottom of the hole.
