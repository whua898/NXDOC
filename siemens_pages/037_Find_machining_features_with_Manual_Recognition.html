Find machining features with Manual Recognition

  1. In the Feature Name box, type a name and press Enter or Tab.

  2. Click Select Floor Face and select the feature's floor.

  3. Click Select Wall Face and select the feature's walls.

  4. Click Add.

    One feature existing within the selected floors and/or walls will appear in the list.

  5. Repeat the above steps for each new feature.

  6. To modify an added feature, select it in the Recognized Features list. You can edit the floors and/or walls by changing their selections.

  7. When you are done, click OK,

    The software adds the features listed to the Machining Feature Navigator.
