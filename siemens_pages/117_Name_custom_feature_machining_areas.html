Name custom feature machining areas

NX automatically creates machining areas for step hole features. This example shows how to group the faces of a slot feature into machining areas and name the machining areas.

  1. Choose Main Menu→PMI→Note.

    Tip:

    If PMI is not available, choose Application tab→Design group→PMI .

    The Note dialog box is displayed.

  2. In the Associated Objects group, click Select Object .

  3. Select the floor of the open slot.

  4. In the Text Input group, under Formatting, type Floor.

  5. In the Origin group, click Specify Location.

  6. Select a location to position the note.

  7. In the Associated Objects group, click Select Object .

  8. Select the walls of the open slot.

  9. In the Text Input group, under Formatting, type Walls and then position the note.

  10. Click Close.

    In the graphic window, NX displays two PMI notes attached to the part.

    1 PMI note = Walls

    2 PMI note = Floor

    In the Part Navigator, there are two Note objects under the PMI node.

    PMI
    Note (1)
    Note (2)

  11. Save the part.

    12. When you teach NX to recognize this feature, NX uses the PMI notes associated with the faces to define the machining areas.
