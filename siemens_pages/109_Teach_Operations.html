Teach Operations

Use the Teach Operations command to teach NX new machining rules from a set of existing operations within Manufacturing. The new machining rules are automatically generated and stored in a machining knowledge library. The following parameters are automatically defined:

  • Feature parameters in the rule application criteria

  • Tool parameters in the tool query

  • Cutting parameters

  • Non-cutting move parameters

  • User defined events

  • Cycle parameters

  • Geometry parent

  • KF parameters

Immediately after the new machining rules are generated, you can use the Create Feature Process command to create the same set of operations, for features with the same dimensions, in all your parts.

To make the rules more general, so that you can apply them to features with different dimensions, you must edit the rules in the Machining Knowledge Editor (MKE). To create general rules without using the MKE application, use the NX command Create Operation Sets.
